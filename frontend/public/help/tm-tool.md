# 工装管理：类型与清单

工装管理用于登记工厂里的**工装、夹具、模具**等辅助生产工具，建立一本"有什么、有多少、什么状态、什么时候该保养"的台账。模块分两级：先建**类型**（如"冲压模具""焊接夹具"），再在类型下逐条登记**工装夹具清单**。

```
工装夹具类型（分类 + 保养规则）──→ 工装夹具清单（逐条台账）
```

> 菜单路径：**MES 管理 → 工装管理 → 工装夹具类型**、**MES 管理 → 工装管理 → 工装夹具清单**。

---

## 一、先建类型，再登记清单

类型是清单的"分类模板"，决定了两件事：**这类工装要不要一物一码**（是否编码管理），以及**按什么周期保养**。清单新增时必须选一个类型，所以请先把类型建全。

### 第 1 步：建类型

1. 打开**MES 管理 → 工装管理 → 工装夹具类型**。
2. 点**新增**，填**类型编码**（可打开"自动生成"开关让系统编一个）和**类型名称**。
3. 选择**是否编码管理**：
   - **是**：这类工装每件单独建台账、单独跟踪（适合模具、贵重夹具）。选择后需填**保养类型**和**保养周期**。
   - **否**：这类工装按数量批量管理（适合量大、可互换的低值夹具），不跟踪保养。
4. 确认**是否启用**为"是"，点**确定**。

> **类型编码保存后不能改**。改错了请停用该类型，重新建一个。

### 第 2 步：登记清单

1. 打开**MES 管理 → 工装管理 → 工装夹具清单**。
2. 点**新增**，填**工装夹具编码**（同样支持"自动生成"）和**工装夹具名称**。
3. 选择**工装夹具类型**——下拉框里只会出现**启用中**的类型。
   - 选了"编码管理"的类型：**总数量、可用数量自动固定为 1**，不能改；**保养类型**自动带出类型上设好的值。
   - 选了普通类型：手工填**总数量**，**可用数量**会自动跟随总数量。
4. 按需补充**品牌**、**规格型号**、**下次保养日期**、**状态**（默认"在库"）、**备注**。
5. 点**确定**保存。

> **工装编码保存后不能改**，台账也不提供删除——登记错的请用"停用"（见下文）。

## 二、字段说明

### 工装夹具类型

| 字段 | 说明 |
|------|------|
| 类型编码 / 类型名称 | 必填；编码唯一，保存后不可改 |
| 是否编码管理 | "是"=一物一码逐件跟踪；"否"=按数量批量管理 |
| 保养类型 | 每天 / 每周 / 每月 / 每季 / 每半年 / 每年 / 按使用次数（仅编码管理时填） |
| 保养周期 | 正整数，单位跟随保养类型（如保养类型选"每月"、周期填 3，即"每 3 个月"） |
| 是否启用 | 停用的类型不出现在清单的类型下拉里 |

### 工装夹具清单

| 字段 | 说明 |
|------|------|
| 工装夹具编码 / 名称 | 必填；编码保存后不可改 |
| 工装夹具类型 | 必填，决定数量和保养字段的行为 |
| 品牌 / 规格型号 | 选填，用于检索区分 |
| 总数量 / 可用数量 | 编码管理的工装固定为 1；普通工装可用数量默认跟随总数量，可手改 |
| 状态 | **在库 / 使用中 / 保养中 / 报废**，由管理员手工维护 |
| 下次保养日期 | 手工登记；到期的可在列表"下次保养日期"列一眼看出 |
| 是否启用 | 列表上的开关，替代删除 |

## 三、日常维护

- **查找**：清单页可按编码、名称、类型、品牌、规格、状态组合搜索；类型页可按编码、名称、保养类型搜索。
- **查看**：点清单行的**名称**（或类型行的**类型编码**）可打开只读详情。
- **修改**：选中一行点**修改**，或点行尾的铅笔图标。编码不可改。
- **停用 / 启用**：列表"启用"列的开关，确认后立即生效。**停用的类型不能再被新清单选用；停用的工装保留台账但不再参与业务**。
- **领用与归还**：目前系统不记录领用流水，由管理员在工装上手工把状态从"在库"改为"使用中"，归还时改回"在库"，并同步修正**可用数量**。
- **保养**：到保养期后把状态改为"保养中"，保养完改回"在库"并更新**下次保养日期**。
- **报废**：把状态改为"报废"，建议同时停用，台账留痕。
- **导出**：两个页面都有**导出**按钮，可按当前搜索条件导出 Excel 盘点表。

## 四、与生产的关联

目前工装管理是**独立台账模块**：生产工单、工艺路线、报工等生产环节**暂不引用**工装档案，系统也不会根据生产动作自动变更工装状态或数量。工装的状态、可用数量、下次保养日期全部由管理员手工维护，系统负责保存和检索。

## 五、常见问题

**问：为什么没有"删除"按钮？**
答：类型和清单都不提供删除，防止历史台账被抹掉。登记错或不再使用的，用列表上的"启用"开关**停用**即可。

**问：清单新增时下拉里找不到某个类型？**
答：该类型被停用了。到**工装夹具类型**里把它的"启用"开关打开，再回到清单页刷新即可。

**问：选了类型后，数量和保养类型为什么不能改？**
答：这是"编码管理"类型的规则——一物一码，数量恒为 1，保养类型跟随类型设置。如果想按数量批量管理，请把类型的"是否编码管理"设为"否"再重新登记。

**问：到了保养日期系统会自动提醒或自动改状态吗？**
答：不会。系统只在列表显示"下次保养日期"，请管理员定期按该列排序查看，手工把状态改为"保养中"并在保养后更新日期。

**问：编码填错了怎么办？**
答：编码保存后不能修改，也不能删除该条。请停用这条记录，重新按正确编码登记一条。
