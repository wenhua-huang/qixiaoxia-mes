# 库存盘点：盘点方案与盘点任务

仓库用了一段时间，账面数和货架上的实际数量难免对不上。**库存盘点**就是定期把实物数一遍，和系统账面数核对、找出差异、查明原因，并把结果记录下来留痕。

本系统的盘点分两步走：先在**盘点方案**里定好"这次盘哪个仓库、打算哪天盘"，再在**库存盘点**里逐物料登记盘点任务，现场数完后回填实盘数和差异。

```
建盘点方案 ──→ 登记盘点任务（逐物料）──→ 现场点数 ──→ 回填实盘数与差异 ──→ 差异调整（杂项出入库）
```

> 菜单路径：**MES 管理 → 仓库管理 → 盘点方案**、**MES 管理 → 仓库管理 → 库存盘点**。

---

## 一、先弄清两个概念

| 概念 | 在哪个菜单 | 管什么 |
|------|-----------|--------|
| **盘点方案** | 仓库管理 → 盘点方案 | 一次盘点行动的总体安排：盘哪个仓库、什么类型、计划哪天盘、进行到哪一步 |
| **盘点任务** | 仓库管理 → 库存盘点 | 方案下逐条物料的盘点记录：账面多少、实盘多少、差异多少、谁盘的、什么原因 |

一个盘点方案对应多条盘点任务，盘点任务上填的**盘点方案编码**就是两者的关联。

> **注意**：建了方案后系统**不会**自动生成盘点任务，需要在「库存盘点」里逐条新增。

---

## 二、第一步：建盘点方案

1. 打开 **MES 管理 → 仓库管理 → 盘点方案**。
2. 点列表上方的「**新增**」。
3. 填**盘点方案编码**（手工编写，建议有规律，如 PD20261016-01）。
4. 填**盘点方案名称**（如"10 月原料仓全盘"）。
5. 填**盘点类型**：全盘填 `FULL`，抽盘填 `PARTIAL`，循环盘点填 `CYCLE`；不填默认为全盘。
6. 填**盘点仓库名称**（本次要盘的仓库）。
7. 选**计划盘点日期**。
8. 填**状态**：准备中填 `PREPARE`，开始盘后改 `TAKING`，盘完改 `COMPLETED`，差异调整完改 `ADJUSTED`；不填默认为准备中。
9. 点「**确定**」保存。

方案建好后，可以随时在列表里按**方案编码、方案名称、盘点仓库名称**搜索查找；执行到下一阶段时，选中该方案点「**修改**」更新状态。

---

## 三、第二步：登记盘点任务

盘点方案定好后，在 **MES 管理 → 仓库管理 → 库存盘点** 里为要盘的每种物料建一条任务：

1. 打开 **MES 管理 → 仓库管理 → 库存盘点**。
2. 点「**新增**」。
3. 填**盘点任务编码**（手工编写，可与方案编码呼应）。
4. 填**盘点方案编码**（填上一步建好的方案编码，把任务挂到方案下）。
5. 填**物料编码、物料名称、规格型号、单位名称**（要盘什么料）。
6. 如按批次管理，填**批次编码**；如有库位管理，可填仓库、库区、库位信息，把任务精确到具体位置。
7. 填**账面数量**：盘点前到 **仓库管理 → 库存现有量** 查该物料的账面数，抄到这里。
8. 点「**确定**」保存。状态不填时系统默认记为**待盘点**。

每种物料（每个批次、每个库位）一条任务，逐条登记完，本次盘点的范围就定下来了。

> 任务较多时，可点列表上方的「**导出**」把任务清单导成 Excel，打印出来带到现场逐条点数。

---

## 四、第三步：现场盘点，回填实盘数

1. 盘点当天，对照导出的盘点表（或列表页面）到货架逐条清点实物数量。
2. 回到 **MES 管理 → 仓库管理 → 库存盘点**，找到对应任务，点「**修改**」。
3. 填**实际盘点数量**（数出来的实物数）。
4. 填**差异数量**（实盘数减账面数，多了为正、少了为负；**系统不会自动计算，需自己核对后填写**）。
5. 有差异的，填**差异原因**（如"发料漏记""损耗""来料短装"）。
6. 填**盘点人**和**盘点日期**。
7. 把**状态**改为 `TAKEN`（已盘点），点「**确定**」。

所有任务都回填完，回到 **盘点方案** 把方案状态改为 `COMPLETED`（已完成）。

---

## 五、第四步：差异处理（盘盈 / 盘亏）

盘点出差异后，**系统不会自动调整库存**。按以下方式处理：

1. **盘盈**（实物比账面多）：到 **MES 管理 → 仓库管理 → 杂项入库** 做一张杂项入库单，把多出来的数量入到账上。
2. **盘亏**（实物比账面少）：到 **MES 管理 → 仓库管理 → 杂项出库** 做一张杂项出库单，把少了的数量从账上出掉。
3. 调整完成后，回到 **库存盘点**，把对应任务的**状态**改为 `ADJUSTED`（已调整），表示这条差异已经处理。
4. 全部差异处理完，把**盘点方案**的状态改为 `ADJUSTED`。

这样账实重新一致，且每一次盘点、每一条差异、每一次调整都有记录可查。事后可以在 **仓库管理 → 库存事务** 里看到杂项出入库留下的流水。

---

## 六、状态说明

**盘点方案状态：**

| 状态 | 含义 |
|-----|------|
| 准备中 `PREPARE` | 方案已建，还没开始盘 |
| 盘点中 `TAKING` | 现场盘点进行中 |
| 已完成 `COMPLETED` | 所有物料都盘完、实盘数已回填 |
| 已调整 `ADJUSTED` | 差异已全部处理完毕 |

**盘点任务状态：**

| 状态 | 含义 |
|-----|------|
| 待盘点 `PENDING` | 任务已建，还没盘（新建默认） |
| 已盘点 `TAKEN` | 实盘数和差异已回填 |
| 已调整 `ADJUSTED` | 该条差异已通过杂项出入库处理 |

> 两个页面都有「**删除**」按钮。误建的单据可以删掉；但已经回填了实盘数和差异的任务建议保留，作为盘点留痕。

---

## 七、盘点类型怎么选

| 类型 | 适用场景 |
|------|---------|
| 全盘 `FULL` | 月末、年末把整个仓库的物料全部盘一遍 |
| 抽盘 `PARTIAL` | 平时抽查部分物料，重点核对高价值或流动快的料 |
| 循环盘点 `CYCLE` | 按计划分批轮盘，这周盘 A 区、下周盘 B 区 |

盘点类型只是对本次盘点范围的标记，方便事后按类型追溯，具体操作流程三种类型都一样。

## 八、常见问题

**问：建好盘点方案后，为什么「库存盘点」里没有任务？**
答：系统不会根据方案自动生成任务，需要到「库存盘点」里点「新增」，逐物料登记并填上对应的方案编码。

**问：盘点期间系统会锁住库存、不让做出入库吗？**
答：不会。请自行安排盘点窗口，盘点该仓库期间尽量避免收发货；如果盘点期间确实发生了出入库，回填实盘数时要把这部分数量考虑进去。

**问：填了实际盘点数量，差异数量为什么没变？**
答：差异数量不会自动计算，需要人工核对"实盘 − 账面"后手工填写，同时填上差异原因。

**问：盘盈、盘亏会自动改库存吗？**
答：不会。盘盈请到「杂项入库」补入，盘亏请到「杂项出库」冲出，调整完把任务状态改为已调整。这样每一笔调整都有单据可查。

**问：账面数量在哪里查？**
答：在 **MES 管理 → 仓库管理 → 库存现有量** 按物料、仓库查询；物料的每一笔进出可在 **库存事务** 里追溯。

**问：状态栏为什么要填英文？**
答：页面表单的状态栏有取值提示（如待盘点 `PENDING`、已盘点 `TAKEN`、已调整 `ADJUSTED`），照着提示填对应代码即可；新建时不填，系统会按默认状态记录。

**问：盘点任务建错了怎么办？**
答：还没回填实盘数的，直接选中点「删除」即可；已经回填过数据的，建议修改纠正而不是删除，保留盘点痕迹。

## 九、相关功能

- **库存现有量**（MES 管理 → 仓库管理 → 库存现有量）：盘点前查账面数量的地方。
- **库存事务**（MES 管理 → 仓库管理 → 库存事务）：查每笔出入库流水，排查差异原因时用。
- **杂项入库 / 杂项出库**（MES 管理 → 仓库管理）：处理盘盈、盘亏的正式单据。
- [订单到交付主流程](pro-workflow.md)：了解采购入库、生产领料、销售出库这些日常业务如何改变库存。
- [转移调拨与杂项出入库](wm-transfer.md)：盘盈盘亏确认后，用杂项出入库调整账面库存的操作步骤。
- [二维码扫码作业指南](qr-code-scan.md)：物料批次码的打印与扫码，帮助快速定位要盘点的批次。
