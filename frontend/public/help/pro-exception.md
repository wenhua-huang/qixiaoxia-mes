# 生产异常：上报与处理

生产过程中出现"做坏了、没料了、完不成了、客户退回了"等情况时，操作员随手在手机上上报一张**异常单**，主管在电脑上定责、补全、选择处理方式，系统自动驱动后续的返工 / 补料 / 改期。**异常单处理完之前，对应工单无法完工**——这保证了异常不会被遗漏。

```
操作员上报 ──→ 待处理 ──→ 主管定责补全 ──→ 选出口处理 ──→ 已关闭
                                            │
                                        报错单可作废
```

> 菜单路径：**生产管理 → 异常台账**（列表）、**异常单详情**（点列表任意一行进入）。

---

## 一、四类异常，上报时怎么选

| 异常类型 | 适用场景 | 主管补全时必填 |
|---------|---------|--------------|
| **质量数量** | 做坏了、做少了 | 质量小类（做坏了 / 做少了）、可使用数量、是否需返工 |
| **缺料** | 物料没到、不够用 | 缺料物料、缺料数量、预计到货日期 |
| **进度延迟** | 无法按计划时间完成 | 原计划完成时间、新预计完成时间、延迟原因 |
| **客户退货** | 客户把货退回来了 | 退货数量、退货原因、客户是否接受返工 |

> **异常类型上报后不能改**。选错了不要紧——主管可以把这张单作废，重新上报一张正确的。

---

## 二、上报异常（操作员）

### 手机端（推荐）

1. 打开**报工**页面，选中正在做的那道**工序任务**。
2. 页面下方出现红色「**⚠ 报异常**」入口，点进去（质检不合格被拦截时也可以从这里上报）。
3. 在四张卡片中点选**异常类型**（质量数量 / 缺料 / 进度延迟 / 客户退货）。
4. 填**影响数量**（选填，多少个产品受影响）。
5. 填**异常说明**（必填，写清楚发生了什么、坏在哪、缺什么料、为什么延迟）。
6. 现场拍照（选填，最多 **9 张**，单张不超过 **10MB**）。
7. 点**提交异常单**。成功后提示"异常单已提交，待主管处理"，自动返回。

### 电脑端

1. 打开**生产管理 → 工序任务**列表。
2. 找到对应任务，点行尾的「**报异常**」按钮（已完成 / 已取消的任务不能上报）。
3. 表单内容与手机端相同，填完提交。

> 上报后不需要通知主管——工单列表会显示红色"**异常N**"角标，工单详情页顶部会出现红色警示区，异常台账里也能看到。

---

## 三、主管处理（异常台账）

主管在**生产管理 → 异常台账**看待处理（红色）的单子，点开进入详情，按三步走：

### 第 1 步：定责与补全

在详情页"定责与补全"卡片中：

1. 选择**责任方**：本厂工序 / 供应商 / 客户。
2. 按异常类型补齐专属字段（见上面表格，比如缺料要选缺料物料、填缺料数量）。
3. 核实**影响数量**（可修正），点**保存补全**。

> **责任方选定后不能改**。选错了只能作废这张单、重新上报。

### 第 2 步：选出口处理

点**选出口处理**，七种处理方式按用途分两组：

| 出口 | 干什么用 | 系统自动做什么 | 选后状态 |
|-----|---------|--------------|---------|
| **开返工任务** | 做坏的部分返工重做 | 以原任务为模板生成"（返工）"任务，进入排产 | 处理中 |
| **开补做任务** | 做少的数量补齐 | 生成"（补做）"任务，进入排产 | 处理中 |
| **开补料采购** | 缺料需要采购 | 生成一张**草稿**采购单（采购员补供应商后下发） | 处理中 |
| **顺延改期** | 进度延迟改计划 | 原任务的计划完成时间直接改为新时间 | 处理中 |
| **报废** | 做坏的部分直接报废 | 需显式填报废数量（不会自动带影响数量） | 已关闭 |
| **让步接收** | 有瑕疵但可接受放行 | 填写让步理由（必填） | 已关闭 |
| **退款结单** | 客户退货退钱了结 | 填写退款结论（必填） | 已关闭 |

- **回流类**（返工 / 补做 / 补料 / 改期）：单据进入"处理中"，生成的返工任务 / 采购单可以在详情页点开跟踪。
- **终结类**（报废 / 让步 / 退款）：选完直接"已关闭"，无需再做第 3 步。

### 第 3 步：关闭异常单（仅回流类）

返工完成、补料到货、改期执行之后，回到异常单详情点**关闭异常单**，填一句处理结论即可。

### 作废（报错了单）

上报对象挂错了、类型选错了，且单子还在"待处理"状态时，可以点**作废**，填原因留痕。作废的单不再参与任何统计和拦截。

---

## 四、状态说明

| 状态 | 含义 | 还能做什么 |
|-----|------|-----------|
| **待处理**（红） | 刚上报，等主管接手 | 定责补全、选出口、作废 |
| **处理中**（黄） | 已选回流出口，返工 / 补料 / 改期进行中 | 关闭 |
| **已关闭**（绿） | 处理完毕 | 只能查看 |
| **已作废**（灰） | 报错单，留痕备查 | 只能查看 |

> 异常单**不能删除**。要抹掉一张报错的单，用"作废"代替。

---

## 五、异常与生产流程的联动

- **工单列表**：有未关闭异常的工单显示红色"异常N"角标。
- **工单详情**：顶部红色警示区逐条列出未关闭的异常单，可点开处理。
- **工序任务列表**：异常单生成的返工 / 补做任务带红色"异常"标记，"关联异常单"列可直接跳回异常详情。
- **完工硬拦**：只要工单下还有**未关闭**的异常单（作废的不算），系统就拦住建单完工，提示先处理关闭。这保证每张异常都有下文。

## 六、常见问题

**问：责任方为什么不能改？**
答：责任方决定了异常走返工还是找供应商 / 客户处理，选定即锁定防止扯皮。选错了请作废重报。

**问：工单为什么不能完工？**
答：看下异常台账里该工单有没有"待处理 / 处理中"的异常单，处理完并关闭（或作废）后才能完工。

**问：异常单能删除吗？**
答：不能。异常单是质量留痕的一部分，报错的情况用"作废"，会保留原因备查。

**问：照片有什么限制？**
答：最多 9 张，单张不超过 10MB，支持 jpg / png / webp 等常见图片格式。

**问：上报之后在哪看处理进度？**
答：操作员可以看工单详情页的红色警示区；主管在异常台账里看状态（待处理 → 处理中 → 已关闭），处理中还能点开生成的返工任务 / 采购单跟踪。

**问：选"开补料采购"后采购单在哪？**
答：在**采购管理 → 采购单**里，状态是草稿，采购员补充供应商等必要信息后正常下发。
