# 质量管理（IQC / IPQC / OQC / RQC）

质量管理模块覆盖来料、生产过程、出货、退料四个环节的检验，把"检没检、合不合格"直接卡在业务动作上——**未检验或检验不合格，就不能过账 / 入库 / 发货 / 退料。**

```
采购到货 ──→ IQC 来料检 ──→ 入库过账
报工/入库 ──→ IPQC 过程检 ──→ 产品入库
销售出库 ──→ OQC 出货检 ──→ 发货确认
生产退料 ──→ RQC 退料检 ──→ 退库过账
```

四类检验单共用一套配置（检测项目、检验模板、缺陷字典）和同一套录入 / 判定界面，操作方式一致，区别只在触发环节和拦截的业务单据。

> 菜单路径：**质量管理 → 检测项目 / 检验模板 / 缺陷字典 / 来料检验单 / 过程检验单 / 出货检验单 / 退料检验单**。

---

## 一、先做配置：让系统知道"检什么、怎么判"

检验单不会凭空生成。系统按"**物料绑定了哪套模板**"来决定一张业务单据要不要检验、检验哪些项目、合格标准是什么。

### 1. 检测项目（质量管理 → 检测项目）

检测项目是检验的最小单位，例如"克重""色差""尺寸""退料原因确认"。每个项目有：

- **项目编码 / 名称**
- **适用检验类型**：IQC / IPQC / OQC / RQC（决定它出现在哪类检验单上）
- **结果录入方式**：
  - 数值型：填数字，可设标准值与上下限，系统自动判定合格 / 不合格
  - 文本型：填文字说明
  - 字典型：从下拉里选结果
  - 计数型：填整数（清点类项目）
  - 附件型：上传图片或文件
- **检测工具 / 检测方法 / 单位**：展示给检验员参考

### 2. 缺陷字典（质量管理 → 缺陷字典）

登记可能出现的缺陷，例如"破损""色差""印刷错位"。每条缺陷有：

- **缺陷编码 / 名称**
- **适用检验类型**（IQC / IPQC / OQC / RQC）
- **缺陷等级**：致命（CR）/ 严重（MAJ）/ 轻微（MIN）
- **默认处置方法**

判定时，检验员在检验单上"维护缺陷记录"，从这里勾选缺陷并登记数量。

### 3. 检验模板（质量管理 → 检验模板）

模板把一组检测项目打包，并可绑定到具体物料。一个模板包含两块：

- **检测项明细**：选哪些检测项目、显示顺序、标准值 / 上下限
- **适用物料**（"适用产品"页签）：指定哪些物料用这套模板，并为每个物料设置判定阈值：
  - **抽检量**：要检多少件
  - **Ac 值（允收数）**：最多允许几件不合格
  - **致命 / 严重 / 轻微缺陷率上限（%）**

> **关键**：只有在"适用物料"里绑定了模板的物料，对应业务单据才会自动生成检验单并被拦截。没有绑定模板的物料免检，业务照常进行——这样可以逐个物料上线，不影响现有流程。

一个模板可同时适用于多种检验类型（在模板的"适用检验种类"里勾选 IQC / IPQC / OQC / RQC）。

## 二、检验单的四种来源与拦截点

检验单由业务单据**自动生成**，不需要手工建单（IPQC 除外，见下）。一张业务单据有多个物料时，系统**按物料拆成多张检验单**，分别判定。

| 检验类型 | 触发动作 | 拦截的业务动作 | 列表里的"来源单据" |
|---------|---------|--------------|-----------------|
| **IQC 来料检验** | 采购入库单保存时 | 入库单**过账** | 采购入库单 |
| **IPQC 过程检验** | 生产报工、产品入库时 | 产品入库**过账** | 工单 / 报工单 / 入库单 |
| **OQC 出货检验** | 销售出库单保存时 | 出库单**发货确认** | 销售出库单 |
| **RQC 退料检验** | 生产退料单保存时 | 退料单**执行退库** | 生产退料单 |

### IQC 来料检验

采购到货后做入库单，保存时系统为每个绑定了 IQC 模板的物料生成一张来料检验单。入库单点"过账"时：

- 有未完成的 IQC 单 → 拦截，提示"需来料检验合格后方可过账"
- 检验判定**合格**或**让步接收** → 允许过账
- 判定**不合格** → 拦截，按让步接收流程处理或退货

### IPQC 过程检验

IPQC 有两种生成方式：

1. **自动生成**：生产报工、产品入库时，为绑定了 IPQC 模板的产品生成过程检验单，拦截入库过账。
2. **手工建单**（质量管理 → 过程检验单 → "手工建单"）：巡检员可主动建单，选择工单和模板，检验类型分**首检 / 巡检 / 完工检 / 抽检**。

> 这是四类检验里唯一支持手工建单的，用于工序巡检、首件确认等不依附某张单据的场景。

### OQC 出货检验

销售出库单保存时，为绑定了 OQC 模板的产品生成出货检验单。点"发货确认"时必须检验合格 / 让步接收，否则拦截。

### RQC 退料检验

生产退料单保存时，为绑定了 RQC 模板的物料生成退料检验单。点"执行退库"时必须检验合格 / 让步接收，否则拦截。退料检验单额外有两个检验员填写的字段：

- **退料原因**：文字描述为何退料
- **责任归属**：供应商 / 生产部门 / 仓储部门 / 其他

## 三、录入与判定（四类检验单操作一致）

以任意一张检验单为例：

1. 在检验单列表点**"录入检验"**（只有"待检验 / 检验中"状态可录入；已完成的点"详情"只读查看）。
2. 在抽屉里：
   - 上半部分是单据基本信息（物料、来源单据、抽检量 / Ac 值、缺陷率阈值），由来源单据自动带出，只读。
   - **实际检测数量**可调整（默认等于抽检量）。
   - "检测项实测值"表格逐行录入：
     - 数值型填数字，右侧实时显示该行合格 / 不合格
     - 文本型填说明
     - 计数型填清点结果
     - 可选填每行的致命 / 严重 / 轻微缺陷数
   - 点"维护缺陷记录"可登记缺陷明细（选缺陷字典里的项、数量、处置方法）。
3. 点**"保存"**暂存录入内容。
4. 点**"执行判定"**：
   - 系统按实际检测数、Ac 值、三档缺陷率自动算出结果
   - **合格**：状态变"已完成"，结果为"合格"，来源业务单据放行
   - **不合格**：可选择"按不合格提交"（拦截业务），或填写**让步理由**后"让步接收"（放行但留痕）
5. 判定后单据锁定，检测项和缺陷记录不可再改。如需作废，点列表里的"作废"（仅待检验 / 检验中可作废，作废后来源单据可重新生成检验单）。

> 判定完成后，系统自动给建单人关闭一条"待检验"待办（首页待办里能看到）。

## 四、在业务单据上看检验状态

采购入库、产品入库、销售出库、生产退料等列表都有一列**"检验状态"**：

- **待检验**（蓝）：检验单已生成但还没判定，点击可跳到对应的检验单列表（已按该单据过滤）
- **让步接收**（黄）：判定为让步接收
- **检验合格**（绿）：判定合格，可继续业务动作
- **检验不合格**（红）：判定不合格，业务被拦截
- **"-"**：该单据没有需要检验的物料（未绑定模板），不拦截

这一列的状态和拦截判定口径一致，不会出现"列表看着合格、实际操作却被拦"的情况。

## 五、常见问题

**Q：为什么我的入库单没有生成检验单？**
A：检查该物料是否在检验模板的"适用物料"里绑定了对应类型的模板（IQC / IPQC / OQC / RQC）。没绑定就是免检。

**Q：一张入库单有多个物料，为什么只生成了部分检验单？**
A：只有绑定了模板的物料才会生成检验单。多物料会拆成多张检验单分别判定，全部合格后入库单才能过账。

**Q：判错了能改吗？**
A：已判定（已完成）的检验单不可修改。可作废后由来源单据重新触发生成新的检验单；判定结果和让步理由都会留痕。

**Q：让步接收和合格有什么区别？**
A：让步接收是不合格但经审批放行，业务能继续走，但单据上明确标记为"让步接收"并记录让步理由，便于追溯和质量分析。

**Q：检验项目 / 模板能随便改吗？**
A：停用的检测项目和模板不会影响已生成的检验单（生成时已快照了标准值）。修改模板只影响之后新生成的检验单。
