# 生产领料与生产退料

生产开工后，车间要从仓库领料才能干活：先在电脑上按工单开一张**领料单**，审核、预占库存后，仓管在电脑上分批**发料出库**（车间也可以用手机扫码发料）。工单做完或料用不完时，再从原领料单开一张**退料单**把余料退回仓库。绑定了退料检验模板的物料，必须先通过**退料检验**才能退库入账。

```
领料：从工单生成 ──→ 提交审核 ──→ 审核通过 ──→ 预占库存 ──→ 发料出库 ──→ 已发料 ──→ 关闭
                        │（退回）                │（可释放预占）   （可分多次，部分发料）
退料：从领料单生成 ──→ 草稿 ──→（需检物料：退料检验合格/让步）──→ 执行退库 ──→ 已退库
```

> 菜单路径：**MES 管理 → 仓库管理 → 生产领料**、**MES 管理 → 仓库管理 → 生产退料**。
> 手机端：APP 工作台「仓储管理」分组，点「**领料单**」（或「扫码发料」）进入。

---

## 一、开领料单（从工单生成）

领料单只能**从生产工单生成**，不能凭空手工开单，保证领的料和工单 BOM 对得上。

1. 打开**MES 管理 → 仓库管理 → 生产领料**，点列表上方的「**从工单生成**」。
2. 在弹出的工单列表中选一张**待生产或生产中**的工单（其他状态的工单不会出现在列表里）。
3. 系统自动按工单 BOM 拉取领料明细（只含本厂工序的物料；如果工单全是外协工序，系统会提示走外协发料模块）。
4. 核对并调整**申请数量**，选择发料**仓库**（必填）、库区，需要时指定**流转卡**（不选则自动取工单默认卡）。
5. 填领料日期和备注，点「**确定**」保存，领料单编码由系统自动生成，状态为**草稿**。

> 明细和 BOM 不一致时，可在「领料明细」页签点「**重新从BOM拉取**」覆盖当前明细。草稿状态下可以随时修改；草稿和待审核状态的单子可以直接删除。

---

## 二、审核：提交 → 通过 / 退回

1. 草稿单点行尾的「**提交审核**」（纸飞机图标），状态变为**待审核**。
2. 审核人在列表中找到待审核的单子，点「**审核通过**」（对勾图标），状态变为**已下达**；数量或物料不对时点「**审核退回**」，单子退回草稿重新修改。
3. 单子多的时候，勾选多行后用工具栏的「**批量提交**」「**批量审核**」一次处理，状态不符或库存不足的单子会被跳过并逐条列出原因。

---

## 三、预占库存

审核通过后、正式发料前，先点「**预占库存**」（锁图标）：

- 系统按**先进先出**（按入库时间，先入库的批次先占）扣减**可用库存**，指定仓库不足时自动跨仓补齐；可用量不足会提示具体物料差多少。
- 预占只是"锁住"库存防止被别的单领走，**现有量不变**，料还在库里。
- 状态变为**已预占**。占错了或这张单不发了，点「**释放预占**」，可用库存恢复，单子回到**已下达**。

> 手机端同样可以预占：APP「领料单」打开一张已下达的单子，底部点「**预占库存**」。

---

## 四、发料出库

### 前提：工单必须先开工

发料出库前系统会检查工单状态，**工单未开工会被拦截**，提示先到「生产工单」点「开工」。开工时系统自动建立流转卡，作为这批物料的追溯载体——没有这个载体，发出去的料无处可挂，追溯链就断了。

### 电脑端发料（仓管）

1. 在**生产领料**列表找到已预占（或部分发料）的单子，点行尾「**发料出库**」（上传图标）。
2. 弹窗上半部分列出每行物料的申请量、已发量、未发量，下半部分录入本次发料。
3. 点「**添加发料明细**」，选择领料行、填写本次发料量（不能超过未发量）。
4. 批次默认"**按预占发料**"（预占的是哪个批次就发哪个）；要换批次时点下拉另选，会显示各批次的仓库和可用量。
5. 点「**确认发料**」，系统扣减现有库存并记录流水；弹窗下方可查看历史发料记录。
6. 没发完的单子状态为**部分发料**，可再次进入继续发；全部发完自动变为**已发料**。

### 手机端扫码发料（仓管 / 班组长）

1. APP 工作台「仓储管理」点「**领料单**」（或「扫码发料」），列表可按 全部 / 待发料 / 发料中 / 已完成 筛选。
2. 打开一张**已预占**的领料单，点底部「**扫码发料**」。
3. 扫物料的批次二维码（或手动输入 / 粘贴物料编码后点「添加」），系统自动匹配领料行，并默认带出全部未发量。
4. 扫批次码会自动预选该批次；要换批次或改回按预占发料，点"批次"一栏重新选择。
5. 确认数量后点「**提交发料**」，提示发料成功后自动返回。

> 手机端也可以直接「**关闭领料单**」（已发料 / 部分发料状态的单子详情页底部）。

## 五、领料单状态说明

| 状态 | 含义 | 还能做什么 |
|-----|------|-----------|
| **草稿** | 刚建单，可编辑 | 修改、提交审核、删除、作废 |
| **待审核** | 已提交，等审核 | 审核通过、审核退回、删除、作废 |
| **已下达** | 审核通过，未占库存 | 预占库存、作废 |
| **已预占** | 已锁定可用库存 | 发料出库、释放预占、作废 |
| **部分发料** | 分批发料中 | 继续发料、关闭、作废 |
| **已发料** | 全部发完 | 关闭、开退料单 |
| **已关闭** | 领料业务结束，终态 | 只能查看 |
| **已作废** | 报错单，留痕备查 | 只能查看 |

> 非终态的单子都可以「**作废**」，需填写作废原因留痕。关闭后不可再操作。

## 六、生产退料（余料退回仓库）

工单完工或物料用不完时，把剩余物料退回仓库。退料单**必须关联原领料单**，且只退"发了但没用掉"的部分。

### 第 1 步：从领料单生成

1. 打开**MES 管理 → 仓库管理 → 生产退料**，点「**从领料单生成**」。
2. 弹窗只列出**已发料**状态的领料单，并显示每张单的**可退量**（可退量 = 已发料量 − 工单已报工消耗量；已全部消耗的单显示"无可退"，不能选）。
3. 双击或点「选择」选中一张领料单，系统自动生成退料草稿，只把有剩余的物料拉成退料行，数量默认是可退的差额。
4. 调整**退料数量**、**批次号**、退料日期和备注（工单、原领料单、仓库自动带出，不可改），点「**保存**」，状态为**草稿**。

> 同一张领料单同时只能有一张未完成的退料单，防止重复退料造成库存虚高。明细拉错了可在草稿状态点「**重新从领料单拉取**」。

### 第 2 步：退料检验（仅绑定了检验模板的物料）

- 物料如果绑定了**退料检验模板**，保存退料单时系统会自动生成一张**退料检验单**（待检验）。
- 退料单列表的「**检验状态**」列显示 待检验 / 检验合格 / 让步接收 / 检验不合格，点标签可直接跳到**质量管理 → 退料检验单**处理。
- **检验合格或让步接收后，才能执行退库**；未检验或不合格会被拦截。没有绑定检验模板的物料免检，可直接退库。

### 第 3 步：执行退库

1. 在退料单列表找到草稿状态的单子，点行尾「**执行退库**」。
2. 系统弹出确认提示：**执行后将增加库存且不可撤销**。
3. 确认后库存现有量增加、生成库存事务记录，退料单状态变为**已退库**，业务结束。

> 草稿状态的退料单可以修改或删除；已退库的单子只能查看，不能改也不能删。

| 退料单状态 | 含义 | 还能做什么 |
|-----------|------|-----------|
| **草稿** | 已建单，未入账 | 修改、执行退库、删除 |
| **已退库** | 退库完成，库存已增加 | 只能查看 |

## 七、常见问题

**问：点发料出库时提示"工单尚未开工"怎么办？**
答：按提示先到「生产工单」把工单开工，开工时系统会自动建立流转卡作为物料追溯载体，然后再回来发料。

**问：预占库存和发料出库有什么区别？**
答：预占只是扣减"可用量"、把料锁住，实物还在库里；发料出库才真正扣减"现有量"，料离开仓库挂到工单上。发料前必须先预占。

**问：一张领料单能分几次发料吗？**
答：可以。每次发多少录多少，没发完状态是"部分发料"，可以继续发；累计发满申请量后自动变为"已发料"。

**问：为什么选领料单退料时，那张单选不了 / 显示"无可退"？**
答：只有"已发料"状态的领料单可以退料；可退量 = 已发料 − 已报工消耗，已全部消耗的物料没有剩余可退。另外同一张领料单已有未完成的退料单时，也不能重复开单。

**问：执行退库时被拦截，提示要先退料检验？**
答：该物料绑定了退料检验模板，需要先到**质量管理 → 退料检验单**完成检验，结果为"检验合格"或"让步接收"后再回来执行退库。也可以点退料单列表"检验状态"列的标签直接跳转。

**问：执行退库后发现数量错了能撤销吗？**
答：不能。执行退库直接增加库存且不可撤销，执行前务必核对退料数量和批次。还在草稿状态的单子可以随时修改或删除重开。

**问：领料单为什么删不掉？**
答：只有草稿、待审核状态的领料单可以删除。已审核及之后的单据请用「作废」（需填原因留痕），保证账实可追溯。
