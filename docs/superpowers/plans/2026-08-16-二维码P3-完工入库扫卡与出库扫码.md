# 二维码 P3：完工入库扫卡 + 出库扫码 + 成品标签 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 扫流转卡码完成生产入库收货并展示/打印成品批次标签；出库过账支持扫批次码（扫码枪/手输）自动预填并修复批次码不参与匹配的存量 bug；外协收货列表支持扫卡定位。

**Architecture:** 全部复用既有基建：payload 体系（CARD/MAT）、`/mes/pro/procard/scan/{cardCode}`（返回 card 含 workorderCode）、`/mes/wm/material_stock/scan/{batchCode}`（批次→库存行含 batchId/materialStockId）、H5 相机扫码页回调模式（`pages/mes/pro/scan?callback=1`）、PC 打印三件套（`QRCode.toDataURL` + window.print）。**调研修正**：product_recpt 无 card 列，扫卡经 workorderId 桥接（`list?workorderId=&status=DRAFT` 已支持）；盘点为空壳模块，挪 P4。

**Tech Stack:** 后端 Spring Boot/MyBatis（JUnit5+Mockito）；前端 Vue3+TS；App uni-app（H5 相机页 + App 原生 scanCode 双通道）。

## Global Constraints

- 设计依据：`docs/superpowers/specs/2026-08-13-二维码扫码体系-design.md` §5/§9-P3（盘点移 P4 已在本计划记录决策）。
