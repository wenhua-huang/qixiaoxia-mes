# 外协管理：发料、厂商加工与收货回厂

某道工序厂内做不了（比如分切、印刷），要把物料发给外面的厂商加工，加工完再收回来——这一出一进由**外协单**全程跟踪。本厂负责**发料**和**收货入库**，中间的签收、录加工结果、发货回厂全部由**厂商在手机端**完成，双方看到的是同一张单的不同侧面。

```
本厂建单(草稿) ──→ 执行发料 ──→ 厂商签收 ──→ 厂商录结果 ──→ 厂商完成 ──→ 厂商发货回厂 ──→ 本厂收货入库
   本厂操作          本厂操作       厂商操作      厂商操作        厂商操作       厂商操作          本厂操作
```

> 菜单路径：电脑端 **仓库管理 → 外协管理**；手机端工作台「**外协发料**」「**外协收料**」「**外协单**」（本厂），厂商登录后工作台显示「**外协任务**」分组。

---

## 一、外协单是怎么来的

外协单有两个来源，**同一工单的同一道工序只能有一张外协单**，系统会自动防重：

### 自动生成（推荐）

1. 工艺路线里把工序标记为"外协"并配好默认厂商。
2. 工单按这条路线**开工 / 生成单据**时，系统为每个外协工序自动生成一张**草稿**外协单。
3. 草稿单按工单物料清单预填发料明细，并按库存先进先出预填仓库和批次。
4. 仓管核对无误后执行发料（见下文），不合适的草稿单可以删除。

### 手工新建

1. 电脑端打开**仓库管理 → 外协管理**，点「**外协发货**」（手机端进「外协发料」点「＋ 新建」）。
2. 选择**外协厂商**（供应商档案中厂商类型为"外协"的才能选到）。
3. 可选关联**生产工单**，选了工单还能再选**流转卡**和**外协工序**。
4. 逐行添加**发料明细**：物料、数量、发出仓库。
5. 确认提交。电脑端提交即直接扣库存发料；手机端按工单扫码建单后会生成草稿，需再执行发料。

> 如果工序已经存在外协单，手机端建单页会直接显示该单状态并阻止重复创建。

---

## 二、本厂操作

### 执行发料（草稿 → 已发料）

电脑端在**仓库管理 → 外协管理**：

1. 在列表找到**草稿**状态的外协单（可按单号、厂商、状态筛选）。
2. 点行尾「**执行发料**」，或勾选多张草稿单后点工具栏「**批量执行发料**」。
3. 确认后系统扣减库存，单据变为"已发料"，关联流转卡标记为"外协中"。

手机端在工作台点「**外协发料**」：

1. 列表默认显示"待发料"的草稿单，点单进入。
2. 可修正每行的**仓库**（从有库存的批次里选）和**数量**，先点「保存发料行」。
3. 点「**执行发料**」，确认后扣库存、单据变"已发料"。

> 草稿单还没扣库存，建错了可以删除（电脑端行尾「删除」）；一旦执行发料就不能删了。

### 收货入库（厂商已发货 → 已收货）

厂商发货后系统会**自动生成来料检验单**。收货前先完成检验：

1. 质检员在**来料检验**中找到该外协单生成的检验单，判定合格或让步接收（电脑端外协单列表的"检验状态"列、手机端单上的「去检验」按钮都能直接跳过去）。
2. 仓管在**仓库管理 → 外协管理**找到"已发货"的单，点「**收货**」（或勾选多张点「**批量收货**」）。
3. 手机端则在工作台点「**外协收料**」，列表默认显示"待收货"的单，点单进入核对厂商录入的收货明细，点「**确认收货**」。
4. 收货成功后：物料**入库加库存**（按厂商录入的明细生成新批次）、自动生成**外协报工**、流转卡**推进到下一工序**。

> 绑定了检验模板的物料，检验单未判定合格 / 让步接收前，**收货会被系统拦下**。

### 查看与跟踪

- 电脑端外协单列表：按单号、厂商、状态、来源（通用 / 分切）筛选，点「详情」看发料明细和收货明细。
- 手机端工作台「**外协单**」：按状态筛选，点单看明细；已收货的单仍可查看检验结果。

## 三、厂商操作（手机端）

厂商员工用本厂管理员开通的**外协厂商账号**登录手机端，工作台只显示「**外协任务**」分组，且**只能看到自己厂商的单**。

### 第 1 步：签收（已发料 → 厂商已签收）

1. 工作台点「**我的外协任务**」，找到"已发料"的单。
2. 实物到货核对无误后，点单上的「**签收**」。
3. 签收后物料保管责任转移到厂商，可以开始录入加工结果。

### 第 2 步：录入加工结果（→ 加工中）

1. 点单上的「**录入结果**」进入录单页。
2. 逐条添加**产出明细**：填数量；分切单还要填每条的**门幅**和**克重**（同规格可用"批量添加"一次生成多条，最多 50 条）。
3. 可选填生产批号、生产日期、有效期（不填系统用收货日期兜底）。
4. 点「**提交加工结果**」。单据进入"加工中"。

### 第 3 步：补录与完成（加工中 → 已完成）

- 分批产出的，加工中可以反复进入点「**补录**」追加，页面会显示"已录 / 应录"进度。
- 累计录满发料量时，单据**自动变为"已完成"**。
- 做不出满量（短交）时，点「**手动完成**」结束加工。

> 累计录入量**不允许超过发料量**，超量提交会被拒绝。

### 第 4 步：发货回厂（已完成 → 已发货）

1. 加工完成后点单上的「**发货回厂**」（或列表上的「发货回厂」）。
2. 确认后单据变"已发货"，系统同时生成本厂的来料检验单，等本厂检验、收货。

> 发货后不可修改。历史单据在「**外协历史**」里查看。

## 四、状态说明

| 状态 | 含义 | 下一步谁操作 |
|-----|------|-------------|
| **草稿** | 单已建好，还没扣库存 | 本厂：执行发料 / 改发料行 / 删除 |
| **已发料** | 库存已扣，料在发往厂商途中 | 厂商：签收 |
| **厂商已签收** | 厂商收到货，保管责任转移 | 厂商：录入结果 |
| **加工中** | 厂商已录入部分结果，可分批补录 | 厂商：补录 / 手动完成 |
| **已完成** | 录满或手动完成，加工结束 | 厂商：发货回厂 |
| **已发货** | 货在回厂途中，检验单已生成 | 本厂：检验 → 收货 |
| **已收货** | 本厂已入库，报工和流转卡已推进 | 只能查看 |
| **已关闭** | 流程终结 | 只能查看 |

> 手机上部分状态的叫法略有差异（如"已完成"也叫"加工完成"、"已发货"即"厂商已发货"），指的是同一个状态。

---

## 五、与生产和流转卡的联动

- **排产任务**：外协工序的任务不占厂内机台，任务名带"-外协"后缀，由外协收货自动推进完成。
- **扫码报工拦截**：操作员扫流转卡时，如果下一道是外协工序，系统提示"下一道工序为外协工序，请在厂商端录结果"，**厂内不能对这道工序报工**。
- **流转卡状态**：执行发料后卡标记为"外协中"；本厂收货后自动建报工并把卡推进到下一道工序。
- **库存批次**：发料扣的是原材料批次，收货入库的是加工后产品的**新批次**，母卷与子卷的转换关系全程可追溯。

## 六、常见问题

**问：为什么外协发货里选不到某个供应商？**
答：只有供应商档案中厂商类型为"外协"（或两者兼有）的供应商才能做外协厂商，请先到供应商档案中维护。

**问：同一道工序能发两次外协吗？**
答：不能。同一工单的同一道工序只允许存在一张外协单，重复创建会被系统拒绝。要换厂商只能删掉未发料的草稿单重建。

**问：执行发料后发现发错了怎么办？**
答：已发料的单不能删除。请让厂商照常签收并把料原样录回、发货回厂，本厂收货后料就回到库存了；草稿状态的单则可以直接删除重建。

**问：厂商实际做出来的比发料量少（短交）怎么办？**
答：厂商按实际数量录入结果后点「手动完成」即可发货回厂，系统按实收数量入库，不要求录满发料量。

**问：厂商能录入超过发料量的数量吗？**
答：不能。累计录入量超过发料量时提交会被拒绝，页面也会提前给出超量提示。

**问：收货按钮为什么点不了 / 收货被拦截？**
答：两种常见原因：一是厂商还没点"发货回厂"（只有"已发货"状态才能收货）；二是该物料绑定了检验模板，来料检验单还没判定合格或让步接收，请先完成检验。

**问：厂商用什么登录、能看到什么？**
答：本厂管理员在**系统管理 → 用户管理**为厂商员工建账号，角色选"外协厂商"并关联对应厂商。厂商登录手机端后只有「我的外协任务」「外协历史」两个入口，且只能看到自己厂商的单，看不到本厂其他数据。

**问：外协回来的料在哪看检验结果？**
答：电脑端外协单列表的"检验状态"列可点击跳到来料检验单；手机端点开外协单详情，有"来料检验"入口。
