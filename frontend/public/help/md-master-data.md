# 主数据管理：物料、客户、供应商等基础档案维护

主数据是全系统的"字典"：销售订单要选客户、工单要选物料、派产要派到工作站、采购下单要选供应商。**这些档案不先建好，后面的业务单据根本开不出来。** 本文面向数据管理员和计划员，说明每个页面维护什么、哪些字段必填、以及档案之间的先后关系。

> 菜单位置：**MES 管理 → 主数据管理** 下的七个页面：物料主数据、物料分类、供应商管理、客户管理、计量单位、车间管理、工作站管理。

---

## 一、为什么先维护主数据：谁引用了谁

| 主数据 | 被哪些业务引用 | 缺失时的后果 |
|--------|--------------|-------------|
| **计量单位** | 物料的主单位 / 辅助单位、各单据数量单位 | 新增物料选不到单位，保存不了 |
| **物料分类** | 物料建档时必选分类，并决定物料是原料 / 半成品 / 成品 | 新增物料无法归类 |
| **物料** | BOM、工艺路线、生产工单、销售订单、采购订单、外协单、质检模板、库存出入库 | 工单、订单、采购单全部开不出来 |
| **客户** | 销售订单、销售出库、销售退货 | 无法下销售订单、无法发货 |
| **供应商** | 采购订单、外协单、供应商退货 | 无法采购、无法发外协 |
| **车间** | 工作站必须挂在车间下 | 建不了工作站 |
| **工作站** | 派产任务、报工、换型、人员绑工位、排产看板 | 工单无法派产到具体机台和人 |

> 一句话：**先有档案，后有单据**。新厂上线或新产品投产前，先按下面的顺序把主数据补齐。

---

## 二、建议维护顺序

1. **计量单位**（物料建档要用）。
2. **物料分类**（先搭好分类树，再在分类上配扩展属性）。
3. **物料主数据**（成品、半成品、原料都建档；成品的 BOM 在物料里维护）。
4. **客户管理、供应商管理**（采购和销售开单要用；供应商可顺带维护"供应物料"）。
5. **车间管理 → 工作站管理**（工作站依赖车间；工作站还要选工序，工序在"生产管理 → 工序管理"维护）。
6. 以上就绪后，再去维护**工艺路线**（生产管理 → 工艺路线），之后即可正常开销售订单、转工单、派产。

---

## 三、通用操作约定（七个页面通用）

- **新增 / 修改**：点列表上方「新增」，或点行尾「修改」。带 \* 的为必填项。
- **没有删除按钮**：主数据一律不提供物理删除，用列表里的「**启用**」开关做**停用**。停用后新单据选不到它，历史单据数据完整保留。
- **编码保存后不可改**：新增时填的编码，保存后编辑框置灰。物料、客户、供应商、车间、工作站的新增弹窗都带「**自动生成**」开关，打开后系统按编码规则自动出号，避免重号。
- **导出**：列表上方「导出」可下载当前查询结果为 Excel。

## 四、计量单位

路径：**MES 管理 → 主数据管理 → 计量单位**

维护物料和业务单据用到的所有单位（个、千克、米、卷……）。

**关键字段**

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 单位编码 | 是 | 保存后不可改，建议全大写，如 PCS、KG |
| 单位名称 | 是 | 显示名，如"个"、"千克" |
| 主单位 | 否 | **留空表示本单位就是主单位**；选了主单位则表示这是辅助单位 |
| 换算率 | 选了主单位才出现 | 含义：**1 本单位 = 多少主单位**（如"箱"的主单位是"个"，换算率填 250 表示 1 箱 = 250 个） |
| 是否启用 | 是 | 默认启用 |

> 注意：已停用的单位在主单位下拉里不可再选。单位建错不要删（也删不了），停用即可。

## 五、物料分类

路径：**MES 管理 → 主数据管理 → 物料分类**

分类是一棵**树**（如：原料 → 纸张 / 油墨；成品 → 纸袋 / 纸盒）。物料建档时必挂一个分类。

**关键字段**

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 分类编码 | 是 | 保存后不可改 |
| 分类名称 | 是 | 树和物料下拉里显示的名字 |
| 排序 | 是 | 同级显示顺序 |
| 物料/产品 | 自动 | **从父分类继承**，取值为：原料 / 半成品 / 成品 / 辅料 / 包材。建大类时定好，子类自动跟随 |

**操作要点**

1. 在树形列表某一行点「新增」，即在**该分类下建子类**（父分类自动带入、不可改）。
2. 「物料/产品」属性决定挂在该分类下的物料算原料还是成品——**这个区分影响物料编码的自动出号规则和后续业务归类**，建大类时务必选对。
3. 行尾「**扩展属性**」：为该分类勾选需要填写的自定义属性（如"克重""抗压强度"），可设必填。父分类配过的属性子类**自动继承**（标记"继承"，不能在本类移除），通常只需在大类上配一次。也可以现场「+ 新建属性」：填属性编码（大写字母开头，只能含大写字母 / 数字 / 下划线）、名称、类型（文本 / 数字 / 下拉 / 开关 / 日期），创建后自动绑到当前分类。配完记得点「保存」。
4. 工具栏「展开/折叠」控制整棵树的开合；停用某个分类用「启用」开关。

## 六、物料主数据

路径：**MES 管理 → 主数据管理 → 物料主数据**

系统最核心的档案。左侧是分类树（点分类过滤右侧列表），右侧是物料列表，支持按编码 / 名称 / 规格搜索，"产品类型"可筛 SPU（标准品）/ 变体。

**新增物料（基本信息页）**

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 物料编码 | 是 | 保存后不可改；可开「自动生成」按分类对应的规则出号（在分类树上先点中分类，新增时会自动带入） |
| 物料名称 | 是 | — |
| 分类 | 是 | 决定该物料是原料 / 半成品 / 成品等 |
| 主单位 | 是 | 从计量单位里选，库存和单据默认按主单位计量 |
| 辅助单位 + 换算率 | 否 | 选了辅助单位后出现换算率，含义：**1 主单位 = 多少辅助单位** |
| 规格型号 / 产品尺寸 / 装箱规格 / 印刷要求 | 否 | 按产品实际情况填，工单会引用 |
| 启用批次管理 | 否 | 默认开；开后出入库按批次跟踪 |
| 安全库存 | 否 | 打开后可填最低 / 最高 / 预警库存 |
| 高价值物资、是否启用、备注 | 否 | — |

**编辑物料时多出三个页签**

- **扩展属性**：按物料所属分类的配置动态生成填写项（在"物料分类"页面配，见第五节），必填项不填保存不了。
- **BOM 组成**：维护这个成品 / 半成品由哪些子物料构成——点「新增」选子物料，填**用量**（必填）、**单位**、**损耗率**（0~1 之间的小数，0.05 表示 5%）。**工单转产时的物料清单就来自这里**，成品投产前必须配好。
- **批次配置**：勾选该物料的批次要记录哪些信息（生产日期、有效期、供应商、销售订单号、生产工单、工作站、纸卷号、门幅等 16 项），配完点「保存批次配置」。

> 变体物料（列表编码旁带黄色"变体"标）挂在某个父产品下，编辑时能看到"父产品"信息。

## 七、客户管理

路径：**MES 管理 → 主数据管理 → 客户管理**

**关键字段**：客户编码（必填，可自动生成）、客户全称（必填）、简称、类型（内贸 / 外贸 / 现货）、业务员、联系人、联系电话、收货地址、是否启用。

> 销售订单、销售出库、销售退货都从这里选客户。**收货地址建议维护完整**，发货环节要用。停用后新订单选不到该客户，历史订单不受影响。

---

## 八、供应商管理

路径：**MES 管理 → 主数据管理 → 供应商管理**

**关键字段**

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 供应商编码 | 是 | 可自动生成 |
| 供应商全称 | 是 | — |
| 供应商类型 | 否 | 原材料供应商 / 外协加工商 / 两者皆是。**选了外协相关类型会出现"外协工厂"字段**，用于多工厂外协场景 |
| 等级 | 否 | A-优秀 / B-良好 / C-一般 / D-待评估 |
| 结算方式 / 付款条件 | 否 | 月结 / 现结 / 其他 |
| 合作状态 | 否 | 合作中 / 暂停 / 待审核 / 终止，默认"合作中" |
| 联系人、社会信用代码、地址等 | 否 | — |

**编辑时多出"供应物料"页签**：维护这家供应商供哪些料，可设**首选**开关、**最小起订量**、**提前期（天）**——采购和缺料补货时参考。同一物料可挂多家供应商，用"首选"标出默认供货方。

---

## 九、车间管理

路径：**MES 管理 → 主数据管理 → 车间管理**

**关键字段**：车间编码（必填，可自动生成）、车间名称（必填）、车间地址、**负责人**（从系统用户里选）、是否启用。

> 车间是工作站的上一级。先建车间，才能建工作站。

## 十、工作站管理

路径：**MES 管理 → 主数据管理 → 工作站管理**

工作站就是派产的最小单位（一台印刷机、一条制袋线）。派产、报工、换型、排产看板都按工作站组织。

**关键字段**

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 编码 | 是 | 可自动生成 |
| 名称 | 是 | 如"1号印刷机" |
| 所属车间 | 是 | 从已建车间里选 |
| 类型 | 否 | 印刷机 / 全自动制袋机 / 半自动制袋机 / 其他 |
| 工序 | 否 | 从"生产管理 → 工序管理"已维护的工序里选，表示该工位干哪道工序 |
| 产能(个/时) | 否 | 排产参考 |
| 状态 | 否 | 空闲 / 运行中 / 保养中 / 故障，默认"空闲" |

**编辑时多出两块子表**

- **关联设备**：把设备管理里的设备挂到该工位（可多台）。
- **操作人员**：把系统用户绑到该工位，并指定角色——**操作工 / 调机工 / 检验员**。手机端报工、按工位派活依赖这里的人员绑定。

> 设备和人员绑定要先保存工作站（编辑状态下）才能维护。

## 十一、常见问题

**问：物料（客户 / 供应商…）为什么删不掉？**
答：主数据一律不提供删除。已被工单、订单、库存引用的档案删掉会让历史单据断链，所以系统用列表里的「启用」开关代替——**停用即"作废"**：新单据选不到，历史数据完整保留。

**问：编码填错了能改吗？**
答：不能。所有主数据的编码保存后即锁定（编辑框置灰）。填错了只能停用这条、用正确编码重建一条。建议新增时打开「自动生成」开关让系统出号。

**问：新增物料时选不到计量单位 / 分类？**
答：先去对应页面维护：单位在「计量单位」里建并启用，分类在「物料分类」树里建。两处备齐后物料才能保存。

**问：原料、半成品、成品在哪里区分？**
答：不在物料本身，而在**分类**上。物料分类带"物料/产品"属性（原料 / 半成品 / 成品 / 辅料 / 包材），子类继承父类，物料挂到分类下即自动归类。

**问：辅助单位的换算率到底怎么填？**
答：两个地方方向相反，注意区分——「计量单位」页填的是 **1 本单位 = 多少主单位**；「物料」页填的是 **1 主单位 = 多少辅助单位**。

**问：物料的 BOM 在哪里维护？**
答：在「物料主数据」里打开该成品的**修改**弹窗，切到「BOM 组成」页签维护子物料、用量和损耗率。新建物料保存后才出现该页签。

**问：工作站里选不到车间或工序？**
答：车间先在「车间管理」建；工序在「生产管理 → 工序管理」维护，不在主数据模块。

**问：停用了一家还在供货的供应商会怎样？**
答：已有采购单、外协单不受影响照常执行，但新单据选不到这家。停用前请确认没有在途业务。

**问：分类上配的扩展属性，物料里怎么看不到？**
答：两个常见原因：属性配完没点「保存」；或属性绑在别的分类上——扩展属性按分类生效，物料只显示**自己所挂分类（含父类继承）**的属性。
