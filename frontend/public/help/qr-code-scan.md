# 二维码扫码作业指南

系统为生产、仓储环节的关键单据和实物生成二维码，扫一扫就能识别身份、带出信息、直接操作，省去手工输单号、选批次的麻烦。

本文介绍有哪几种码、分别在哪里打印、各端怎么扫，以及每个业务场景的标准操作。

## 三种二维码

| 码 | 内容样例 | 贴在什么上 | 谁来打印 |
|----|---------|-----------|---------|
| **流转卡码** | `QXX\|CARD\|CARD20260816001` | 工单流转卡（随产品走的工艺卡） | 派产后在「生产管理 → 流转卡」打印 |
| **物料批次码** | `QXX\|MAT\|BAT20260816001` | 采购到货 / 完工入库的每一批物料标签 | 采购入库、产品入库确认后，在单据行打印 |
| **纸卷码** | `QXX\|ROLL\|ROLL20260816001` | 分切产生的每一卷成品 / 半成品纸卷 | 在「仓储管理 → 纸卷管理」查看与打印 |

> 码的统一格式是 `QXX|类型|业务编号`。系统内部用它判断"这是一张卡、一批料还是一卷纸"，所以**不要手写或涂改**，用系统生成的标签。

---

## 标签打印机

批次标签、纸卷标签、流转卡标签都按**标签纸规格**（默认 60×40mm）精确排版，连续出纸不浪费。根据打印电脑的环境自动选择打印方式：

| 环境 | 行为 |
|------|------|
| 装了 C-Lodop 打印控件（推荐，打印电脑装一次） | 点「打印」直接出标签，不弹对话框 |
| 未装控件 | 弹浏览器打印对话框，选中标签打印机后打印；页面已按标签纸尺寸排版，不会打歪 |

- **安装 C-Lodop**：到官网 www.lodop.net 下载「C-Lodop」（Windows 版）安装，装完刷新系统页面即可，无需其他配置
- **默认打印机**：控件方式发送到 Windows 的**默认打印机**，打印电脑请把标签打印机设为默认打印机
- **标签规格**：在流转卡、纸卷的二维码弹窗底部可切换（60×40 / 50×30 / 70×50 / 40×30mm），选择后本机记住；批次标签按当前规格直接打印

> 打印机还没买也不要紧：先用浏览器方式也能出标签；买回来装好驱动（USB 或网口均可），再装 C-Lodop，之后就是点一下直接出。

## 各端怎么扫码

### 移动端 APP（原生）
APP 内凡是带「扫一扫」图标的页面，直接调用手机摄像头扫码，识别后自动填入或跳转。

### 移动端 H5（微信 / 浏览器打开）
H5 环境下没有系统级扫码能力，页面内置了网页扫码组件：
- 点「扫一扫」会请求摄像头权限
- 对准二维码即可识别，体验与 APP 一致
- 首次使用需在浏览器 / 微信里**允许摄像头访问**

> 提示：微信里如果弹不出摄像头，点右上角「···」用默认浏览器打开，或检查微信的摄像头权限。

### PC Web 端（扫码枪）
PC 端的出库、发料等页面支持**条码扫描枪**：
- 光标停在「批次码」输入框，扫码枪自动读码填入
- 也支持手动粘贴 `QXX|MAT|...` 后回车，效果相同
- PC 端不调用摄像头，靠扫码枪或手工输入

## 场景一：生产报工扫流转卡

**适用**：操作工看到一张流转卡，想直接报工。

- **APP**：工作台 → 报工 → 扫流转卡码
  - 系统识别工单、当前应报工序，自动带出
  - 直接录入合格数 / 不合格数提交
- **扫码后看到的几种结果**：
  - **可报工**：列出当前可报的工序，直接录数
  - **下一道是外协工序**：提示该工序已外发到厂商加工，本厂无需报工，由厂商在「外协任务」录入结果
  - **无可报工序**：可能工单未派产、或所有工序已完成，按提示处理

> 流转卡记录的是"**已完成到哪道工序**"。扫码后系统自动算出下一道该谁做，包括并行工序的情况，不需要人工判断。

---

## 场景二：采购收货 → 打印批次标签

**适用**：采购到货，仓管收货后要给每批物料贴标签，后续发料才能扫码。

### APP 收货
- 工作台 / 采购管理 → 采购入库 → 扫码或选采购订单
- 录入收货数量、生产日期、有效期
- 确认收货后，APP 会弹窗显示本次生成的**批次码**（可复制）
- 批次标签需在 **PC 端**打印

### PC 端打印
1. 进入「仓储管理 → 采购入库」，打开已确认的入库单
2. 在操作列点 **「打印批次标签」**
3. 系统按行生成标签（同一物料、同一供应商、同一天、同一批号会归为同一个批次码，不重复生成）
4. 标签按当前标签纸规格出纸（见上文「标签打印机」），贴到对应物料上

> 多行采购单：每行物料各自生成批次码，标签按行打印；如果多行物料的关键属性完全一致，会复用同一个批次码而不是重复建批。

---

## 场景三：仓库发料扫批次码

**适用**：车间来领料，仓管扫物料上的批次标签快速定位库存、发料。

- **APP**：仓储管理 → 领料 → 扫码发料
- 扫物料批次码（`QXX|MAT|...`）后：
  - 系统按批次精确找到对应库存批次
  - 自动匹配到领料单明细行（按物料编码）
  - 带出仓库、批次、库存数量，确认发出即可
- 也可扫纸卷码（`QXX|ROLL|...`）查询纸卷信息

> 扫码发料保证发出的批次可追溯，避免手工选错批次。

---

## 场景四：纸卷扫码查询

**适用**：看到一卷纸，想知道它的规格、母卷、当前状态。

- **APP**：扫纸卷码（`QXX|ROLL|...`）直接显示纸卷信息卡片
- **PC**：「仓储管理 → 纸卷管理」每行可查看二维码、补打纸卷标签

---

## 场景五：完工入库

**适用**：生产完工后办理成品入库。

- **APP**：仓储管理 → 产品入库
  - 可扫**流转卡**或**工单号**定位完工工单，也可手动搜索
  - 录入入库数量、箱数、批次信息后确认
  - 确认后显示生成的批次码
- **PC**：「仓储管理 → 产品入库」
  - 已确认 / 已过账的入库单，明细行可 **「打印批次标签」**
  - 确认入库时弹窗提示是否立即打印

---

## 场景六：销售出库精确选批

**适用**：发货时要按指定批次出库，或用扫码枪扫批次标签自动带出。

路径：**仓储管理 → 销售出库** → 打开出库单 → **出库确认（过账）**

- 弹窗顶部有 **「批次码」** 输入框：
  - 用扫码枪扫物料批次码，或手工输入批次码后回车
  - 系统自动定位该批次在出货仓库的库存，取可用数量，带出明细行（产品、批次、仓库、数量）
- 可多次扫码添加多个批次
- 提交前系统会再次校验：每个填了批次码但没匹配上的行会拦截，提示先补全；不会像手工录入那样悄悄变成"先进先出"扣错批次

> 出库时 **批次精确扣减**：扫了哪个批次就扣哪个批次的库存；不填批次才按先进先出自动分配。

---

## 场景七：外协单扫码查找

**适用**：手里有一张流转卡或工单号，想快速找到对应的外协单。

- **APP**：外协单列表 → 顶部搜索栏的「扫一扫」
- 扫流转卡码 / 工单号，列表自动按该工单过滤出相关外协单
- 手动搜索框则按外协单号查找

> 外协单状态含义：草稿 → 已发货 → 厂商已收 → 加工中 → 已完工 → 已发回 → **本厂已收货**。只有最后一步「本厂收货」由本厂仓管操作，其余由厂商在「外协任务」端完成。

## 常见问题

### 扫码后提示"识别不到 / 无效二维码"
- 确认扫的是**本系统生成的码**（以 `QXX|` 开头）
- 码是否破损、反光，换个角度重扫
- PC 端检查扫码枪是否正常输出（可先在记事本里试扫）

### H5 扫码打不开摄像头
- 浏览器 / 微信需要授权摄像头，在地址栏或「···」菜单里允许
- 微信内权限异常时，用系统浏览器打开同一链接重试
- 确认页面是 **https 或 localhost** 访问（浏览器安全策略要求）

### 扫流转卡提示"下一道为外协工序"
- 这是正常提示：该工序已经外发，本厂不需要报工
- 等厂商加工完、本厂收货后，流转卡会自动推进到下一道厂内工序
- 如需查外协进度，到「外协单」列表扫码或手动查找

### 批次码什么时候生成？能重复打印吗？
- 批次码在**入库行保存 / 确认时**生成，不是点打印时才生成
- 同一物料 + 供应商 + 生产日期 + 有效期 + 批号相同，会复用同一批次码，不重复建批
- 标签丢失可在对应入库单上重新打印，批次码不变

### 出库扫码提示"批次不存在"或"仓库不符"
- 该批次可能不在本张出库单的**出货仓库**（系统只取同一仓库的库存）
- 或批次号输入有误，核对标签重新扫
- 确认该批次确实有可用库存（未被其他出库占用）
