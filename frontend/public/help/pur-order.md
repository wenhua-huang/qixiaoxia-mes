# 采购管理：采购订单、入库与退货

采购从一张**采购订单**开始：采购员建单、审批、下单给供应商；货到后仓管用手机登记到货，质检合格后电脑上确认入库；收进来的料有问题，再按批次退给供应商。订单的收货进度全程自动汇总，收不完的部分可以逐行终止，单子最终关闭留档。

```
建采购订单 ──→ 审批 ──→ 下单 ──→ 到货登记(手机) ──→ 检验合格 ──→ 确认收货 ──→ 过账 ──→ 关闭
   ▲                                        │                                    │
   │                                   需检物料自动生成待检单              收来的料有问题 → 采购退货
   └── 生产异常"开补料采购"自动生成草稿单
```

> 菜单路径：**MES 管理 → 采购管理 → 采购订单头**（建单、审批、下单、跟踪）、**采购订单行**（按行跟踪）、**采购订单详情**（单张订单完整视图）；入库和退货在 **MES 管理 → 仓库管理 → 采购入库 / 采购退货**。

---

## 一、建采购订单（采购员）

### 1. 新增订单头

1. 打开**采购管理 → 采购订单头**，点「**新增**」。
2. **单据编号**默认自动生成（右侧绿色开关），需要手工编号时关掉开关自己填。
3. 点**供应商**输入框右侧的放大镜，从供应商列表选择（必选）。
4. 选**采购类型**：纸张 / 辅料 / 包材 / 其他。
5. 确认**下单日期**（默认当天）和**预计到货**日期。
6. **采购人**默认是当前登录人，可改选他人；这批货是为哪个客户订单备的料，可在**关联客户订单**里选对应销售订单（选填）。
7. 点「**保存单据**」。提示"新增成功，请添加订单行"，弹窗下半部分出现"采购订单行"区域。

### 2. 添加订单行

在"采购订单行"区域点「**新增行**」，逐行添加要买的物料：

1. 点**物料**行的「搜索」，从物料主数据里选择（必选）。
2. 核对带出的**规格型号**和**单位**（单位必填）。
3. 填**订购数量**（必填）、**单价**、**税率**。行金额 = 单价 × 数量，自动算；订单头的**采购金额**也随各行自动汇总，不用手填。
4. 纸张类采购可填**预计卷数**；「扩展属性」页签里是从物料主数据带出的门幅、克重等属性，本次要改直接改（只影响本单；长期变更请到物料管理新建物料变体）。
5. 点「**确定**」。行加错可勾选后「删除」。

> 订单行也有状态，跟着订单头一起走；收货后行上能看到**已收数量、已退数量**。

### 3. 另一种来源：生产异常"开补料采购"

生产报缺料、主管在异常台账里选「**开补料采购**」时，系统会自动生成一张**草稿**采购单（缺料物料和数量已带出，供应商待定，并和异常单双向关联）。采购员在**采购订单头**列表里找到这张草稿单，补齐供应商、单价等信息后，走正常的审批、下单流程。详见《[生产异常：上报与处理](pro-exception.md)》。

## 二、审批、下单与跟踪

订单头列表的每行末尾有操作按钮，状态只能按顺序推进，不能跳：

1. **审批**（仅草稿单）：点「审批」确认后，订单变为**已审批**，自动记录审批人。
2. **下单**（仅已审批）：确认已和供应商谈妥，点「下单」，订单变为**已下单**，自动记下下单日期。只有已下单的订单才能收货。
3. **取消**（草稿 / 已审批 / 已下单可用）：整单不要了，点「取消」，在弹窗里选**取消原因**留痕。前提是**所有行都还没有任何收货记录**；已经收过部分货的，请改用下面的"关闭"。

跟踪进度看列表这几列：

- **采购数量**：显示"已收 / 订购"，有取消的还会标红"已取消 xx"。
- **采购金额**：总金额，以及"已收 xx 元 · 已取消 xx 元"。
- **状态**：状态后面出现红色 **⚠** 表示"已超期未到货"（已下单 / 收货中且预计到货日期已过），该催供应商了。
- 点行首的「查看」图标或勾选后点工具栏「查询」，进入**采购订单详情**页：完整订单信息、逐行已收量、行交期、创建/更新记录，并可「**导出 PDF**」「**导出 Excel**」发给供应商或存档。

想按物料维度看（比如查某种纸还有几单没到），用**采购管理 → 采购订单行**：可以按物料、客户订单号、预计到货日期等条件查所有订单的行，直接看到每行的已收货数，也可导出。

## 三、到货入库

收货分两端：**手机做"到货登记"**（只记录货到了多少，不动库存），**电脑做"确认收货"**（检验合格后库存才真正增加）。这样既能在收货现场快速登记，又能保证检验不合格的料不会进库存。

### 1. 手机端：到货登记（仓管 / 收货员）

1. 打开手机端「**待收货**」列表（列出所有已下单、收货中的采购订单），点要收的那张单进入「**到货登记**」；也可以直接在页面顶部输入 PO 单号点「查询」。
2. 核对供应商、采购类型、订单状态。
3. 逐行填**实收数量**，并为每个已填数量的行选择**入库仓库**。
4. 点底部「**确认到货**」按钮提交。

提交后系统只做登记：自动生成一张**草稿入库单**、为批次管理物料生成**批次码**、为需检物料生成**来料待检单**。成功提示里会给出入库单号和批次码，并提醒到电脑端完成质检和确认入库。**此时库存还没有变化。**

> 只有"已下单 / 收货中"的订单能登记；草稿、已审批的订单请先完成下单。

### 2. 电脑端：质检与确认入库（仓管）

1. 打开**仓库管理 → 采购入库**。除了手机登记生成的草稿单，也可以点「**从采购单生成**」直接选一张已下单 / 收货中的采购订单，系统带出待收物料行生成草稿单。
2. 看列表的**检验状态**列：需检物料显示"待检验"，点这个标签可直达检验单列表。先到质量管理做来料检验（见《[质量检验操作指南](qc-quality-inspection.md)》），**检验合格或让步接收后**才能往下走；免检物料显示"-"，不受此限。
3. 草稿单点「**确认收货**」（打勾图标）：系统更新库存并通知采购订单，随后会询问是否**打印批次标签**（非草稿单随时可点打印机图标补打，标签含批次码、物料、数量、仓库，扫码收发料用，见《[二维码扫码作业指南](qr-code-scan.md)》）。
4. 已确认的单点「**过账**」：把已收数量正式回写到采购订单上——订单变为**收货中**；全部行收完时自动变为**已收货**。

> 检验不合格的料不能被确认收货，这是系统硬性拦截，先处理检验单（让步接收或退货）再继续。

## 四、采购退货

已经收进仓库的料要退给供应商，按**批次**退：系统按"物料 + 仓库 + 批次 + 原入库单"列出可退数量（已收 − 已退），不能超退。

### 1. 发起退货（两个入口，向导相同）

- 入口一：**采购管理 → 采购订单头**，在收货中 / 已收货的订单行末点「**退货**」，自动带上该订单。
- 入口二：**仓库管理 → 采购退货**，点「**从采购订单生成**」，选一张收货中 / 已收货的采购订单。

向导分两步：

1. **选择可退批次**：核对退货单号（可点「生成」自动编号），在批次列表里勾选要退的批次，填**本次退货**数量（不超过"可退"列）。如果该订单所有批次都已退完，会提示"无可退数量"。
2. **确认并生成**：核对退货单头和各行数量，点「**确定**」，生成一张**草稿**退货单。

### 2. 退货单确认与过账

1. 在**采购退货**列表找到草稿退货单，点「**确认**」：按批次扣减库存，单据从此不可修改——确认前请核对好数量。
2. 货实际发出后点「**过账**」：回写采购订单的**已退货数量**，订单行上能看到。

## 五、状态说明

### 订单头状态

| 状态 | 含义 | 能做什么 |
|------|------|---------|
| **草稿** | 刚建好或异常开单生成，尚未审定 | 修改、删除、审批、取消 |
| **已审批** | 内部审定通过 | 下单、取消 |
| **已下单** | 已下达给供应商，等到货 | 收货登记、取消、超期催货 |
| **收货中** | 部分物料已收 | 继续收货、行终止/取消、强制关闭、退货 |
| **已收货** | 所有行都收完了（自动推进） | 关闭、退货 |
| **已关闭** | 单据终结归档 | 只能查看 |
| **已取消** | 整单作废，留痕备查 | 只能查看 |

状态推进规则：

- 点「**关闭**」（收货中 / 已收货可用）把单子归档。收货中关闭属于**强制关闭**：未收完的部分被放弃、不可恢复，必须选一个关闭原因。
- 关闭前所有行必须到达终态（收完 / 已取消 / 已终止），否则系统提示先处理未完成行。
- 行全部取消且没有任何收货时，订单头自动变为"已取消"；全部收完自动变"已收货"。

### 订单行的取消与终止收货（收货中精细控制）

在订单头弹窗的"采购订单行"区域，对单行操作：

- **取消**（行还没收过货）：该行的订购数量作废，需选原因。
- **终止收货**（行收了一部分、剩下的不要了）：保留已收数量，放弃未收部分，需选原因。

## 六、常见问题

**问：下单后发现供应商或价格填错了怎么办？**
答：草稿单可以直接修改或删除重来；已审批 / 已下单的单用「取消」（需无收货记录）作废后重建。已经收过货的不能取消，用"关闭"归档。

**问：供应商只交了一部分货，尾数不交了，订单怎么收场？**
答：对没交齐的行用「终止收货」（保留已收、放弃未收），一行货都没到的用行「取消」；然后在订单头点「关闭」，选一个关闭原因即可归档。

**问：确认收货时提示要先检验，是什么情况？**
答：该物料在物料主数据里标了需要来料检验（IQC）。到货登记时已自动生成待检单，到质量管理做完检验且判定"合格"或"让步接收"后，再回来确认收货。免检物料不受影响。

**问：手机上登记到货后，库存怎么没变？**
答：这是设计如此。到货登记只生成草稿入库单，库存要等电脑端「确认收货」才增加，「过账」后已收数量才回写到采购订单。

**问：订单状态旁边的红色 ⚠ 是什么意思？**
答：该单"已超期未到货"——已过预计到货日期但还没收完，需要跟进供应商。

**问：退货能退多少？**
答：按批次退，最多退"可退数量"（该批次已收 − 已退）。退货单确认即扣库存，过账后回写采购订单的已退数量。

**问：生产异常"开补料采购"生成的单在哪？**
答：在**采购管理 → 采购订单头**里，状态是草稿，缺料物料和数量已带好，补上供应商、单价后正常审批下单。

**问：怎么把采购订单发给供应商？**
答：进入**采购订单详情**页，右上角「导出 PDF」或「导出 Excel」即可。
