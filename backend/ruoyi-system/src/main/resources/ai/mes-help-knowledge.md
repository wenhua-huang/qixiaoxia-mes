## 系统功能清单

- 首页：工作台看板
- 基础数据：物料主数据、物料分类、供应商管理、客户管理、计量单位、车间管理、工作站管理、仓库设置、班组设置、排班计划、节假日设置、排班日历、工装夹具类型/清单
- 仓储管理：库存事务、库存现有量、采购入库、采购退货、产品入库、生产领料、生产退料
- 销售管理：销售订单、销售出库、发运登记工作台
- 生产管理：生产工单、工序管理、工艺路线、排产任务、生产报工、流转卡、甘特图排产、换型时间、工单变更、生产看板、物料追溯、生产统计、上下工记录、用户工作站、异常台账
- 质量管理：检测项目、检验模板、缺陷字典、来料检验单、过程检验单、出货检验单、退料检验单
- 采购管理：采购订单头
- 设备管理：设备类型、设备档案
- 外协管理：外协单全流程

- 手机端 App：报工（含扫码）、报异常、报工记录、我的（个人信息）

## 登录与快速上手

- 浏览器打开系统地址，输入账号密码登录（验证码按现场配置可能关闭）。
- 首次使用顺序：基础数据（物料/供应商/客户/车间/工作站/仓库）→ 工艺路线与工序 → 销售订单 → 生产工单 → 排产 → 报工。
- 右上角头像菜单可进入帮助中心、个人中心、退出登录。
- 列表页通用操作：顶部筛选条件查询、工具栏新增/修改/删除/导出，导出为 Excel。
- 编码规则：系统多数单据按编码规则自动生成单号，无需手工编号。

## 销售订单到交付主流程

1. 销售管理录入销售订单（客户、产品、数量、交期）。
2. 按销售订单下达生产工单（也可手工建工单）。
3. 工单按工艺路线拆成工序任务，排产后派工到车间/工作站。
4. 操作员用手机端「生产报工」扫码或选任务报工（数量、工时），报工触发过程检验（配置了检验模板时）。
5. 完成后产品入库，再按销售出库发货、发运登记。
6. 工单完工条件：所有工序完成且无未关闭的生产异常。

## 生产异常：上报与处理

- 四类异常：质量数量（做坏/做少）、缺料、进度延迟、客户退货。
- 上报入口：手机端报工页选中工序任务后点红色「⚠ 报异常」（推荐）；或 PC 端生产管理→工序任务列表行尾「报异常」按钮。
- 上报填写：异常类型（必选，提交后不可改）、影响数量（选填）、异常说明（必填）、现场照片（选填，最多9张、单张≤10MB）。
- 主管处理在生产管理→异常台账，点进详情三步：① 定责与补全（责任方选定后不可改；按类型补专属字段：缺料必填物料+缺料数量，延迟必填原计划/新预计时间+原因，退货必填数量+原因）→ ② 选出口处理（开返工任务/开补做任务/开补料采购/顺延改期＝转处理中；报废/让步接收/退款结单＝直接关闭）→ ③ 处理中完成后回详情「关闭异常单」填结论。
- 报错单可「作废」（填原因留痕，仅待处理状态可作废）；异常单不能删除。
- 联动：工单列表红色「异常N」角标、工单详情顶部红色警示区；有未关闭异常的工单无法完工（系统硬拦）。
- 状态流转：待处理→处理中→已关闭；作废为终态。

## 质量管理：检验（IQC/IPQC/OQC/RQC）

- 四类检验：IQC 来料检验（采购入库拦截过账）、IPQC 过程检验（报工/产品入库拦截过账）、OQC 出货检验（销售出库拦截发货）、RQC 退料检验（生产退料拦截退库）。
- 先配置：检测项目（检验的最小单位，数值/文本/字典等录入方式）→ 缺陷字典（缺陷等级 致命/严重/轻微）→ 检验模板（打包检测项并绑定物料，设抽检量与允收数）。只有绑定了模板的物料才会自动生成检验单。
- 检验单由业务单据自动生成，按物料拆分；判定合格/让步接收后业务才能继续，不合格会被拦截。
- 菜单：质量管理 → 检测项目 / 检验模板 / 缺陷字典 / 各类检验单。

## 二维码扫码作业

- 手机端报工支持扫码：扫流转卡/任务二维码自动定位工序任务，减少手工选择。
- 二维码用于工单、流转卡、库位等场景，扫码后在手机端继续对应操作（报工、查任务）。
- 扫码失败时检查：摄像头权限、二维码清晰度、网络连接；也可改用手工选择任务。

## 销售订单开放接口（API 对接）

- CRM 等外部系统可通过开放接口写入销售订单：在 系统管理→API Key管理 生成接入凭证（明文只显示一次，请妥善保存）。
- 调用时在请求头携带凭证；接口地址以 /open-api/ 开头。
- 凭证可停用/吊销；每个凭证绑定一个工厂，数据互相隔离。

## 手机端 App 使用

- 主要功能：生产报工（选任务或扫码）、报异常（报工页选中任务后点红色「⚠ 报异常」）、报工记录查询、我的。
- 报工流程：选择工单/工序任务 → 填合格数量、工时 → 提交；质检不合格会被拦截，可按提示报异常。
- 照片类上传（如异常现场照片）最多 9 张，单张不超过 10MB。
