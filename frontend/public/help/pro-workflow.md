# 生产主流程：工单 → 报工 → 入库

本文以一个成品的生产过程为例，带你走完系统的核心链路。

## 流程总览

```
创建工单 → 派产（分配人员/设备）→ 工人报工 → 末工序审核 → 自动入库
```

一张工单可能含多道工序，每道工序独立报工，**末工序审核通过后自动生成入库单**，把成品数量写入仓库。

## 前置准备

在创建工单前，确认这些基础数据已维护：

- **物料**（md/item）：成品和所用原料都要先建档
- **工艺路线**（pro/proroute）：定义这道产品有哪些工序、顺序如何
- **工序**（pro/process）：工艺路线里引用的工序单元
- **工作站 / 车间**（md/workstation、md/workshop）：派产时分配到具体位置

> 基础数据缺失会导致工单建不起来或无法派产。

## 第 1 步：创建工单

路径：**生产管理 → 工单管理**

1. 点击「新增」
2. 填写：工单名称、成品物料、计划数量、计划开工/完工时间
3. 选择工艺路线
4. 保存后，工单状态为「草稿」或「待派产」

工单是整条流程的源头，所有报工、入库都挂在它下面。

## 第 2 步：派产

路径：**生产管理 → 工单管理 → 派产**（或在工单详情里操作）

- 把工单的各工序分配给具体的人员、工作站
- 确认后工单进入「已派产」状态，工人即可开始报工

## 第 3 步：报工（工人操作）

报工是产线工人最常用的操作，有两种入口：

### Web 端

路径：**生产管理 → 报工管理**

- 查到自己的工单/工序
- 录入：完成数量、合格数量、不合格数量
- 物料消耗会由系统按 BOM 自动带出，确认即可

### 移动端 APP（推荐产线使用）

- APP → 工作台 → 报工
- 扫码或手动选择工单
- 录入数量、提交

> 报工时**合格数 + 不合格数 = 完成数**，请核对清楚再提交。

## 第 4 步：工序审核 / 入库

- 每道工序报工后由班组长/质检审核
- **末工序审核通过 → 系统自动生成产品入库单**，成品按报工合格数量入库
- 入库单可在「仓储管理 → 产品入库」查看

不需要手动创建入库单，这是系统自动完成的。

## 常见情况

### 中途要改数量怎么办？

- 报工未审核：可直接联系审核人退回，修改后重新提交
- 已审核：走工单变更流程（生产管理 → 工单变更）

### 报错了数据怎么办？

- **不要**直接删改已审核的报工记录，请联系管理员
- 系统有完整的操作日志和库存流水（仓储管理 → 库存流水），可追溯每一笔变动

### 物料消耗不对？

- 报工时的物料消耗是按工单 BOM 自动计算的
- 如发现消耗数量异常，检查：物料 BOM 是否准确、报工数量是否正确
- 可在「生产管理 → 物料追溯」查看每批产品的用料明细
