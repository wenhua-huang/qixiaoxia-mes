# 二维码 P2：物料/卷料批次码 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 仓库工人扫物料批次码(`QXX|MAT|{batch_code}`)即可查库存/匹配发料行并自动选批次；扫卷料码(`QXX|ROLL|{roll_code}`)可查纸卷信息；PC 采购入库页可打印批次标签。

**Architecture:** 复用 P1 的 payload 体系（后端 `QrPayloadType` 已含 MAT/ROLL，App `qrPayload.js` 已解析）。后端新增两个精确反查接口（batch_code/roll_code 均有唯一索引，现无精确查询方法）+ 移动收货返回批次数据；PC 复用 P1 的 A4 打印三件套；App 打通 scanDispatch 的 MAT/ROLL 分发与 scan-query/scan-issue 消费。**调研修正**：批次码在入库单**创建/收货**时生成（非 confirm 时），confirm 时行上已有 batchCode，打印入口纯 UI；卷料码诞生于**分切子卷**（IN_STOCK），非原纸到货。

**Tech Stack:** 后端 Spring Boot 4.0.3/MyBatis（JUnit5+Mockito 单测）；前端 Vue3+TS（复用 `qrcode` 依赖）；App uni-app（复用 `uni.scanCode`）。

## Global Constraints

- 设计依据：`docs/superpowers/specs/2026-08-13-二维码扫码体系-design.md` §4 生成时机矩阵、§6.3 反查接口、§9 P2 工作项。
