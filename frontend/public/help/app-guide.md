# 手机端使用指南

本文面向产线工人、仓管、质检员和外协厂商，介绍如何用手机打开系统、登录，以及报工、打卡、报异常、领料、收货、质检这些最常用的操作。手机端是电脑端的补充：**在电脑端能看到的单据，手机上都能处理；手机上提交的数据，电脑端实时可见。**

---

## 一、怎么打开和登录

### 打开方式

手机端是网页版，**无需下载安装**，任选一种方式打开：

1. 用手机浏览器（推荐 Chrome）打开网址：`http://115.29.234.204/app/`。
2. 或在微信里直接点开这个网址（可把链接收藏或发给同事）。

> 建议把网址加入浏览器书签或桌面快捷方式，以后一键进入。

### 登录

1. 输入管理员分配的**账号**和**密码**。
2. 输入右侧图片上的**图形验证码**（看不清就点一下图片换一张）。
3. 点**登录**，成功后自动进入首页。

> 账号由管理员在电脑端统一开通，手机上没有自助注册入口。忘记密码请联系管理员重置，或登录后在「我的 → 应用设置 → 修改密码」里自行修改。

### 底部三个标签

| 标签 | 用途 |
|------|------|
| **首页** | 欢迎页，日常不用停留 |
| **工作台** | 所有业务功能的入口，干活都从这里进 |
| **我的** | 个人信息、修改密码、退出登录 |

## 二、工作台总览

工作台按业务分组排列，每个人看到的分组可能不同：**外协厂商账号登录后看到的是「外协任务」分组，厂内员工看到的是「生产管理」分组**。各入口一句话说明如下。

### 仓储管理

- **领料单**：查看本厂领料单列表（可按 全部 / 待发料 / 发料中 / 已完成 筛选），点开看明细、执行发料。
- **扫码发料**：扫物料包装上的条码，自动匹配领料单行，确认数量后提交发料。
- **扫码查库存**：扫物料条码或输入物料编码，查该物料在各仓库的现有量、可用量和批次。
- **产品入库**：按工单号查询并登记产成品入库。
- **入库记录**：查询历史产品入库单及明细。
- **销售出库**：销售发货出库的扫码登记。

### 采购管理

- **采购收货**：待收货采购订单列表，点进订单做到货登记。
- **收货历史**：查询已登记的收货记录和详情。

### 生产管理（厂内员工）

- **生产报工**：待报工工序列表，点工序直接进报工页填数量。
- **质检**：待检单列表（过程检 / 来料检 / 出货检 / 退货检），点开录入检验结果。
- **扫一扫**：扫流转卡码、工单码自动跳到报工页；扫物料码跳到库存查询。
- **报工历史**：查询自己提交过的报工记录。
- **工位打卡**：上工 / 下工打卡，记录人在哪个工作站干了多久。
- **打卡历史**：查询自己的上下工打卡记录。
- **外协发料**：待发料的外协单列表，可新建外协单、执行发料。
- **外协收料**：厂商送回后，待收货的外协单列表，点选入库。
- **外协单**：全部外协单列表，可查进度、扫流转卡定位单据。

### 外协任务（外协厂商）

- **我的外协任务**：发给本厂商的外协单，点进去录入加工结果。
- **外协历史**：已完结的外协单记录。

### 系统管理

用户、角色、菜单等九宫格入口目前仅作占位（点了提示"模块建设中"），这些管理功能请在电脑端操作。

## 三、扫流转卡报工（最常用）

报工 = 告诉系统"这道工序我做了多少、好的多少、坏的多少"。扫流转卡是最快的方式。

1. 打开**工作台 → 扫一扫**，把流转卡上的二维码对准取景框（相机不可用时会自动切到手动输入，手输或粘贴卡号即可）。
2. 系统自动识别卡片并跳到报工页，顶部显示"流转卡报工"和当前工序；只有一道可报工工序时会自动选中。
3. 核对**合格数**（必填），按需填**不合格数**、**工废**、**料废**。
4. 如果该工序要求填**工序参数**，按标准范围录入实际值（超范围会标红"偏差"）。
5. 需要时在**备注**里写一句说明。
6. 点底部**提交报工**，确认弹窗后提交，提示"报工提交成功"即完成。

也可以不扫码：打开**工作台 → 生产报工**，在待报工列表里点自己的工序进入；或在报工页顶部手动输入工单号查询，再点选工序。

注意事项：

- 累计合格数超过流转卡数量时，系统会弹"超报提醒"，确认无误再提交。
- 同一工序已有待审核的报工时，提交前会提醒，避免重复报工。
- 显示"不可开工"的工序是质检不合格被拦截，需授权人员放行后才能报工；情况紧急可先点「⚠ 报异常」上报。

## 四、工位打卡（上工 / 下工）

打卡记的是**工时**（人在哪个工位、干了多久），报工记的是**产量**（做了多少件），两者互不替代。建议的节奏：**到岗先打卡上工 → 干活过程中按批报工 → 离岗或下班打卡下工**。

### 上工

1. 打开**工作台 → 工位打卡**。
2. 在"我的工位"里点选自己的工作站；不在列表里就输入工位编码查询，或点右上角"扫码选择"扫工位码。
3. （选填）输入工单号查询并点选**关联任务**，说明这趟活对应哪个工单。
4. （选填）写备注，如换班说明。
5. 点**上工打卡**。

### 下工

1. 打开**工位打卡**，页面顶部显示"在岗中"、上工时间和已工作时长。
2. （选填）写下工备注。
3. 点红色**下工打卡**。

历史记录在**工作台 → 打卡历史**里查。

## 五、报异常

做坏了、缺料了、完不成了、客户退货了，随手在报工页上报，主管在电脑端接手处理。

1. 在**报工页**选中出问题的工序任务，点红色「**⚠ 报异常**」。
2. 在四张卡片里点选**异常类型**：质量数量 / 缺料 / 进度延迟 / 客户退货。
3. 填**异常说明**（必填，写清楚发生了什么）；影响数量选填。
4. （选填）现场拍照，最多 9 张。
5. 点**提交异常单**，提示"异常单已提交，待主管处理"即可，不用另外通知主管。

异常类型提交后不能改，处理进度在电脑端异常台账里看。详细说明见《[生产异常：上报与处理](pro-exception.md)》。

## 六、领料与扫码发料（仓管）

1. 打开**工作台 → 领料单**，顶部按 全部 / 待发料 / 发料中 / 已完成 筛选，点开单据看明细。
2. 发料时打开**扫码发料**，扫物料包装上的条码，系统自动匹配领料单行。
3. 核对"本次发料"数量，需要时点选指定批次（默认按预占发料）。
4. 一张单可连续扫多种物料，扫完点**提交发料**。

拿不准库存时，用**扫码查库存**：扫物料条码或输入物料编码，即可看到该物料各仓库的现有量、可用量和批次，扫卷料码还能看单卷剩余数量。

## 七、采购收货（仓管）

1. 打开**工作台 → 采购收货**，列表里是已下单、待收货的采购订单，可按单号搜索。
2. 点进对应订单，逐行填写**本次到货数量**，需要追溯的填**供应商批号**。
3. （选填）拍照留证、填写物流单号 / 车牌号 / 送货单号。
4. 点**到货登记**并确认。

> 到货登记只生成草稿入库单，**此时库存不变**；待检验合格后由电脑端确认入库，库存才会增加。登记错了能在**收货历史**里查到记录，联系电脑端处理。

## 八、质检（检验员）

1. 打开**工作台 → 质检**，顶部四个页签：**过程检 / 来料检 / 出货检 / 退货检**。
2. 在对应页签里点一张待检单，进入检验录入页，按检验项填结果并提交。
3. 过程检支持两种建单方式：点右下角"**手工建单**"，或点右上角扫码图标**扫流转卡**建单。
4. 出货检、退货检的单据由系统根据出库、退料自动生成，直接点开录入结果即可。

已完成的检验在页面右上角"**检验历史**"里查。

## 九、个人中心（我的）

点底部「我的」：

- **个人信息**：查看昵称、手机号、邮箱、岗位、角色。
- **编辑资料**：修改昵称、手机号等基础信息。
- **修改头像**：点顶部圆形头像，从相册选一张上传。
- **应用设置**：**修改密码**（旧密码 + 新密码两遍）、**退出登录**。
- **常见问题 / 使用说明 / 关于我们**：内置帮助页。

## 十、常见问题

**问：点"扫一扫"相机打不开？**
答：手机浏览器在网址为非安全连接（http）时可能禁止调相机，页面会自动切到**手动输入**模式，手输或粘贴编码即可，功能完全一样。想开相机：在浏览器设置里允许相机权限后重试；仍不行的，按页面红色提示框里的方法（Chrome 的 flags 设置）把本站加入信任名单。

**问：微信里能打开吗？扫码能用吗？**
答：能打开，登录和操作与浏览器一样。微信内置浏览器对相机的支持因手机而异，扫不出来就点"手动输入"输编码。

**问：列表数据不是最新的？**
答：在列表页**下拉刷新**；还不行就退回工作台重新进入，或到「我的 → 应用设置 → 退出登录」后重新登录。

**问：登录时验证码总报错？**
答：验证码区分内容、有时效，点一下图片换一张新的再输；注意别输成上一次的。

**问：扫出来的码提示"暂不支持该类型码"？**
答：系统只认本厂打印的流转卡码、工单码、物料码三类二维码，包装上的厂商原始码请改用"手动输入"输工单号 / 物料编码。

**问：为什么我的工作台没有"生产报工"？**
答：外协厂商账号登录后只显示"外协任务"分组（我的外协任务 / 外协历史），这是正常的；厂内报工入口对厂商隐藏。如果厂内员工也看不到，找管理员核对账号角色。

**问：报工和打卡都要做吗？**
答：都要。打卡记工时、报工记产量，缺一不可：漏打卡影响工时统计，漏报工影响工单进度和计件。
