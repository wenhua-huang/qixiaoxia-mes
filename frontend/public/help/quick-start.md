# 快速上手

欢迎使用企小侠 MES 系统。本文帮你在 5 分钟内了解系统能做什么、怎么找到你需要的功能。

## 登录

1. 打开系统网址（由管理员提供）
2. 输入账号、密码
3. 点击「登录」

> 忘记密码请联系系统管理员重置。

## 系统总览

系统按业务领域划分为以下模块，左侧菜单可找到对应入口：

| 模块 | 中文名 | 主要用途 |
|------|--------|---------|
| 基础数据 | 物料、客户、供应商、单位、车间、工作站 | 所有业务的字典基础，先维护再用 |
| 仓储管理 (wm) | 出入库、库存、调拨、盘点、条码 | 管物料的进出存 |
| 生产管理 (pro) | 工单、工序、报工、工艺路线、排产 | 管生产过程 |
| 质量管理 (qc) | 质检单、不合格品处理 | 管产品质量 |
| 采购管理 (pur) | 采购订单、采购入库 | 管采购进货 |
| 销售管理 (sal) | 销售订单、销售出库、退货 | 管销售发货 |
| 设备管理 (dv) | 设备台账、设备类型 | 管生产设备 |
| 工具管理 (tm) | 工具台账、工具类型 | 管工装工具 |
| 生产排程 (cal) | 日历、班组、计划、假日 | 管生产排程 |
| 系统管理 (sys) | 用户、角色、菜单、字典、日志 | 管账号与权限（管理员用） |

## 典型的一天

不同岗位主要用到的功能：

- **操作工/产线工人**：移动端 APP 报工、领料；Web 端查工单进度
- **班组长**：派产、查看报工记录、看生产看板（pro/dashboard）
- **仓管**：入库单、出库单、领料单、库存查询、盘点
- **质检员**：质检单录入、不合格品处理
- **计划员**：创建工单、排产、工艺路线维护
- **采购员**：采购订单、采购入库
- **销售员**：销售订单、销售出库、发货登记
- **管理员**：系统管理（用户/角色/权限/字典）

## 常用小技巧

- **顶部搜索**：右上角放大镜图标，可全局搜索菜单，快速定位功能
- **面包屑导航**：顶部路径可点击返回上层
- **多标签页**：每个打开的菜单是一个标签，可同时打开多个，点击切换
- **表格筛选**：列表页通常有「搜索」按钮，可按条件筛选数据
- **导出 Excel**：大部分列表页右上角有「导出」按钮

## 遇到问题怎么办？

| 问题 | 解决 |
|------|------|
| 看不到某个菜单 | 没有权限，请联系管理员授权对应角色 |
| 操作提示「无权限」 | 同上，权限点未分配 |
| 数据不显示 | 检查顶部是否选了正确的「工厂」，多工厂环境下数据按工厂隔离 |
| 报工/库存数据对不上 | 不要自行修改，请联系管理员核对，系统有完整操作日志可追溯 |
