# 订单到交付主流程：销售订单 → 生产 → 发货

本文以一张客户订单为例，带你走完从接单到发货的完整链路：

```
销售下单 → 订单确认 → 转工单 → 派产 → 报工 → 自动入库 → 销售出库 → 发货 → （客户签收 / 退货）
```

理解这条线，你就掌握了系统最核心的价值——**销售、生产、仓储数据全程打通，一张销售订单能追溯到每一次报工和每一发出的货。**

> 如果你的业务不经过销售订单（如备货生产、现货），也可以从第 3 步「创建工单」直接开始，前两步可跳过。

## 扫码与标签贯穿全流程

主流程中的关键实物都有二维码，**打印贴码 → 后续环节扫码操作**是推荐作业方式：

```
派产后          报工              入库后            出库
打印流转卡码 ──→ 扫流转卡报工 ──→ 打印批次标签 ──→ 扫批次码精确出库
```

| 码 | 在哪一步生成 / 打印 | 扫码用来做什么 |
|----|-------------------|--------------|
| 流转卡码 `QXX\|CARD\|...` | 第 3 步派产后，在「流转卡」打印 | 第 4 步扫卡报工、第 5 步扫卡入库、外协单扫码查找 |
| 物料批次码 `QXX\|MAT\|...` | 采购入库 / 产品入库确认后打印 | 发料扫码定位批次、销售出库扫码精确扣批 |
| 纸卷码 `QXX\|ROLL\|...` | 分切产生纸卷后打印 | 扫查纸卷规格 / 状态 / 母卷 |

> 标签纸默认 60×40mm，支持标签打印机一键出纸（装 C-Lodop 控件）或浏览器打印对话框降级。码的格式、打印机配置、各端扫码方式详见 [二维码扫码作业指南](qr-code-scan.md)。

## 前置准备

在走流程前，确认这些基础数据已维护：

- **物料 / 产品**（基础数据 → 物料）：成品和原料都要先建档
- **客户**（基础数据 → 客户）：销售订单要选客户
- **工艺路线**（生产管理 → 工艺路线）：定义产品有哪些工序、顺序如何
- **工序 / 工作站 / 车间**：派产时要分配到具体的人和位置

> 基础数据缺失会导致订单或工单建不起来。

## 第 1 步：创建销售订单（销售员）

路径：**MES 管理 → 销售管理 → 销售订单**

1. 点击「新增」
2. 填写订单头：
   - 选择**客户**，填写客户 PO 号、业务员
   - 选择**业务线**（内贸 / 外贸 / 现货）、订单类型（新单 / 返单）
   - 填写订单日期、**需求交期**、付款方式
   - 销售订单号可手填，也可打开「自动生成」开关
3. 在「明细行」里点「添加行」，逐行登记客户要的产品、数量、单价，以及尺寸、印刷、包装等要求
4. 点「保存」

保存后订单状态为 **待确认**。此时订单还可以修改或删除。

## 第 2 步：确认订单并转工单（销售员 / 计划员）

1. 在销售订单列表，找到状态为「待确认」的订单，点操作列的 **「确认」**
2. 订单变为 **已确认**，此时操作列出现 **「生成工单」** 按钮
3. 点「生成工单」，在弹出的向导里：
   - **第一步**：选择要生产的订单明细行（系统会显示订单数、已转数、可转数；一张订单可分多次转、每行可部分转）
   - **第二步**：填写工单信息：工单编码（可自动生成）、计划数量、计划开工 / 完工时间，选择工艺路线
4. 确认后，系统自动生成一张或多张工单，工单上会记录来源销售订单号，可随时反查

> 只有「已确认」的订单才能转工单。订单全部交付后可点「关闭」；误建的订单可「取消」。

---

## 第 3 步：派产（计划员 / 班组长）

路径：**MES 管理 → 生产管理 → 工单管理**

- 上一步生成的工单状态为「待派产」
- 打开工单，把各道工序分配给具体的人员、工作站
- 确认派产后，工人即可在自己的任务列表里看到这张工单

### 打印流转卡标签

派产后系统会生成流转卡（随产品走的工艺卡）。在 **生产管理 → 流转卡** 列表：

- 勾选多张卡点「批量打印」，或打开单张卡点二维码弹窗里的「打印」
- 标签上印有流转卡二维码、工单号、产品、当前工序等信息
- 把标签贴在流转卡 / 实物上，后续工人**扫流转卡码**即可报工，不用手输工单号

> 标签纸规格可在打印弹窗底部切换（默认 60×40mm），选择后本机记住。打印机配置见 [二维码扫码作业指南 → 标签打印机](qr-code-scan.md#标签打印机)。

## 第 4 步：报工（工人操作）

报工是产线工人最常用的操作，有两种入口：

### 移动端 APP（推荐产线使用）

- APP → 工作台 → 报工
- **扫流转卡上的二维码**，系统自动识别工单、当前应报工序（含外协工序判断），无需手选
- 录入完成数量、合格数量、不合格数量，提交

> 扫码后如果提示"下一道为外协工序"，说明该工序已外发厂商加工，本厂无需报工；等厂商完工、本厂收货后流转卡会自动推进到下一道厂内工序。

### Web 端

路径：**MES 管理 → 生产管理 → 报工管理**

- 查到自己的工单 / 工序
- 录入完成、合格、不合格数量
- 物料消耗由系统按工单 BOM 自动带出，确认即可

> 报工时 **合格数 + 不合格数 = 完成数**，请核对清楚再提交。

## 第 5 步：工序审核与自动入库

- 每道工序报工后由班组长 / 质检审核
- **末工序审核通过 → 系统自动生成产品入库单**，成品按合格数量写入仓库
- 入库单可在「仓储管理 → 产品入库」中查看，无需手动创建

### 打印成品批次标签

产品入库确认后，每一批成品会生成**批次码**（`QXX|MAT|...`）。在「产品入库」单据明细行点 **「打印批次标签」**，标签上印有批次二维码、产品、数量、入库单号，贴到成品 / 包装箱上。后续销售出库时扫这个码就能精确按批次发货。

> **原材料批次标签**同理：采购到货在「仓储管理 → 采购入库」确认后，明细行打印批次标签贴到原料上，车间领料时仓管扫批次码发料、保证批次可追溯。批次码在入库确认时生成，标签丢了可以在原单据上补打，批次码不变。

成品入库后，就有库存可供发货了。

---

## 第 6 步：销售出库（仓管）

路径：**MES 管理 → 仓储管理 → 销售出库**

1. 点「从销售订单」，选择要发货的销售订单，系统自动带出客户、产品和待发数量
2. 核对出库明细（产品、数量、仓库），保存，单据状态为「草稿」
3. 点 **「出库确认」**，在弹窗里可用扫码枪**扫物料批次码**：
   - 扫成品 / 包装箱上的批次标签（`QXX|MAT|...`），系统自动定位该批次在出货仓库的库存、带出明细行
   - 可多次扫码添加多个批次；**扫了哪个批次就扣哪个批次**，不会悄悄变成先进先出扣错批
   - 不扫批次则按先进先出自动分配
4. 确认后系统扣减库存，单据变为「已出库」

> 支持分次出库：一张销售订单可以分多张出库单、多次出库确认。

## 第 7 步：发运登记（仓管 / 物流）

在销售出库单上点 **「发运登记」**，进入发运工作台：

1. 新建发运单，选择发货方式（物流 / 快递 / 自提）
2. 填写运单号、车牌 / 司机、收货地址等物流信息，可按箱装箱
3. 提交发运，单据进入「在途」状态
4. 客户收到货后，在发运单上点 **「签收」**，整笔交付完成

> 一张出库单支持分多次发运、部分发货；每次发运的物流信息和回单都会留档可查。

## 第 8 步（可选）：销售退货

若客户退货：

路径：**MES 管理 → 仓储管理 → 销售退货**

1. 新增退货单，关联原销售出库单
2. 登记退货产品、数量、原因
3. 过账后系统自动把退回的产品加回库存，并记录库存流水

## 常见问题

### 不经过销售订单，能直接生产吗？

可以。在「工单管理」里直接「新增」工单即可，这类工单没有关联销售订单，适合备货、现货生产。

### 一张销售订单能分多次生产 / 发货吗？

都可以。
- **生产**：转工单时可只转部分数量，剩余数量后续再转（订单行会显示「订单数 / 已转 / 可转」）
- **发货**：可分多张销售出库单、多次发运

### 中途要改工单数量怎么办？

- 报工未审核：联系审核人退回，修改后重新提交
- 已审核：走「工单变更」流程（生产管理 → 工单变更）

### 报错了数据怎么办？

- **不要**直接删改已审核的报工或出库记录，请联系管理员
- 系统有完整的操作日志和库存流水（仓储管理 → 库存流水），每一笔变动都可追溯

### 怎么查一张销售订单的生产和发货进度？

- 在销售订单列表，可看到订单的状态
- 通过「生成工单」时自动记录的来源单号，在工单管理里查到对应工单及其报工、入库情况
- 在销售出库、发运单里可查到对应的出库和物流记录
