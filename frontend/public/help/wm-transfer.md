# 转移调拨与杂项出入库

仓库里的库存变动，大部分都有"来历"：采购来的走进货入库，生产做出来的走生产入库，卖给客户的走销售出库。但总有一些变动对不上这些常规业务——比如把物料从一个仓库挪到另一个仓库、盘点时发现多了或少了、样品报废了。这类"没有常规业务单据"的库存调整，就用本篇介绍的三个功能：**转移调拨**、**杂项入库**、**杂项出库**。

> 菜单路径：**MES 管理 → 仓库管理 → 转移调拨 / 杂项入库 / 杂项出库**。

---

## 一、三个功能怎么选

| 功能 | 什么时候用 | 对库存的影响 |
|------|-----------|-------------|
| **转移调拨** | 物料在同一工厂的仓库之间挪动位置（仓库、库区、库位级别） | 源仓库减少、目标仓库增加，总量不变 |
| **杂项入库** | 库存"凭空"增加：期初建账导入、盘盈调整、其他无来源的入库 | 库存增加 |
| **杂项出库** | 库存"凭空"减少：盘亏调整、报废、其他无去向的出库 | 库存减少 |

> 判断口诀：**有来有去用调拨，只增用杂项入库，只减用杂项出库**。采购入库、生产入库、销售出库等有正规业务单据的变动，不要用杂项出入库代替。

---

## 二、转移调拨

### 适用场景

- 原材料从主仓库发到车间线边仓。
- 成品从临时存放区移到成品仓的正式库位。
- 同一仓库内，把物料从一个库区 / 库位整理到另一个库区 / 库位。

调拨单支持**跨仓库**（单据头上选源仓库和目标仓库），也支持**跨库区、跨库位**（明细行上分别填源库区、源库位和目标库区、目标库位）。物料有批次管理的，明细行里填上**批次号**，按批次调拨。

### 第 1 步：新建调拨单（单据头）

1. 打开**仓库管理 → 转移调拨**，点列表上方的「**新增**」。
2. 在"单据头"页签填**调拨单号**：可以打开右侧「**自动生成**」开关让系统编号，也可以手工输入。
3. 填**调拨名称**（一句话说明这次调拨干什么，如"原料仓发线边仓"）。
4. 填**源仓库**和**目标仓库**（两个都是必填）。
5. 选**调拨日期**，需要说明的在**备注**里补充。
6. 点「**保存单据**」。

> 调拨单号、源仓库、目标仓库为必填项，缺了保存不了。

### 第 2 步：填调拨明细（调拨明细页签）

1. 单据头保存后，弹出窗口里会出现"**调拨明细**"页签，点进去。
2. 点「**新增行**」，填**物料编码**（必填）、物料名称、规格型号、单位。
3. 填**调拨数量**（必填，最小为 0，支持 4 位小数）。
4. 有批次的填**批次号**。
5. 需要精确到位置的，填**源库区、源库位**和**目标库区、目标库位**。
6. 点「**确 定**」；一张调拨单可以重复上面步骤加多行物料。
7. 明细行可以随时「修改」「删除」，全部录完后关闭窗口即可。

### 修改与删除

- 列表里**草稿**状态的调拨单，行尾有「修改」「删除」按钮；也可以勾选后点列表上方的「修改」「删除」。
- 删除前系统会弹确认框，确认后单据连同明细一起删除。
- 点列表里的**调拨单号**（蓝色链接）可以查看整张单的内容，自动定位到调拨明细页签。

### 按状态查找

列表上方可以按**调拨单号**模糊搜索，也可以按**状态**筛选：草稿、已确认、已过账。状态列以不同颜色的标签显示，方便区分单据处理到哪个阶段。

## 三、杂项入库

### 适用场景

| 入库原因 | 典型用途 |
|---------|---------|
| **期初导入** | 系统上线建账时，把仓库里的现有库存一次性录进来 |
| **盘盈调整** | 盘点时实物比账面多，把多出来的部分入到账上 |
| **其他** | 不属于任何常规业务的入库，如供应商赠品、样品转库存 |

### 新建杂项入库单

1. 打开**仓库管理 → 杂项入库**，点「**新增**」。
2. 填**杂项入库单号**：可打开「**自动生成**」开关让系统编号，也可手工输入。
3. 填**杂项入库单名称**（如"6 月盘盈调整"）。
4. 填**入库原因**：按页面提示填期初导入、盘盈调整或其他。
5. 填**仓库名称**和**入库日期**。
6. 填**入库总数量**和**状态**（草稿 / 已确认 / 已过账）。
7. 点「**确 定**」保存。

### 录入入库明细

1. 打开**仓库管理 → 杂项入库**对应的明细行维护页面，点「**新增**」。
2. 填**物料编码、物料名称、规格型号、单位编码、单位名称**。
3. 填**入库数量**。
4. 有批次的填**批次编码**。
5. 填**仓库、库区、库位**，把物料落到具体存放位置。
6. 点「**确 定**」；每张单可录入多行物料。

### 查找与导出

- 列表上方可按**单号、单名称、仓库名称**搜索。
- 点「**导出**」可把当前查询结果导出为 Excel，用于对账留档。

## 四、杂项出库

### 适用场景

| 出库原因 | 典型用途 |
|---------|---------|
| **盘亏调整** | 盘点时实物比账面少，把亏缺的部分从账上减掉 |
| **报废** | 物料过期、损坏、判废，从库存中销掉 |
| **其他** | 不属于任何常规业务的出库，如样品赠送、内部领用 |

### 新建杂项出库单

操作与杂项入库完全对应：

1. 打开**仓库管理 → 杂项出库**，点「**新增**」。
2. 填**杂项出库单号**（可用「自动生成」）、**杂项出库单名称**。
3. 填**出库原因**：按页面提示填盘亏调整、报废或其他。
4. 填**仓库名称、出库日期、出库总数量、状态**。
5. 点「**确 定**」保存。
6. 在明细行维护页面逐行录入**物料、出库数量、批次编码、仓库 / 库区 / 库位**。
7. 列表同样支持按单号、名称、仓库搜索和「**导出**」Excel。

> 报废的物料建议把批次号填全，事后可以通过批次追溯到这批货是什么时候、从哪张单进来的。

## 五、单据状态说明

三个功能的单据都使用同一套状态：

| 状态 | 含义 |
|------|------|
| **草稿** | 单据刚录入，内容还可以修改、删除 |
| **已确认** | 单据内容已核对无误 |
| **已过账** | 单据已正式生效 |

建议的用法：当天录入先存**草稿**，下班前或月底由负责人核对后改为**已确认**，账务处理完成后标记为**已过账**。草稿状态的调拨单可以直接修改或删除；需要保留痕迹的调整，不要删除单据，用备注说明原因。

## 六、常见问题

**问：同一个仓库内换库位，也要做调拨单吗？**
答：要。调拨单支持源仓库和目标仓库相同、只改库区或库位的场景，在明细行里填好源库位和目标库位即可，这样库存台账里位置才是准的。

**问：盘点多出来了，能不能直接在库存数上改？**
答：不要直接改数。盘盈开一张**杂项入库**（原因选盘盈调整），盘亏开一张**杂项出库**（原因选盘亏调整），每一笔记账都有单据可查，月底对账才对得上。

**问：杂项出入库和采购入库、销售出库有什么区别？**
答：采购入库、生产入库、销售出库等都有对应的业务单据（采购单、工单、销售单）驱动，走各自的功能入口。杂项出入库只用于**没有业务来源**的库存调整，两者不要混用，否则业务台账会缺数。

**问：调拨单建错了怎么办？**
答：草稿状态的调拨单可以直接在列表里点「删除」，或点「修改」改正内容。已经确认的单据建议先改回可编辑状态再处理，或新做一张反向的调拨单冲正。

**问：调拨单、杂项单的单号必须手工编吗？**
答：不用。新增窗口里单号旁边有「**自动生成**」开关，打开后系统自动按规则编号；有特殊编号习惯时再手工输入。

**问：单据上的批次号可以不填吗？**
答：批次管理的物料建议填。调拨、出库时填批次号，才能保证按批次核算的库存（比如先进先出、保质期管理）准确；杂项入库填批次，也方便以后追溯这批库存的来历。

**问：这些单据在哪里能看到最终的库存结果？**
答：到**仓库管理 → 库存现有量**看各仓库 / 库区 / 库位的实时库存，到**仓库管理 → 库存事务**看每一次出入库的流水记录。

## 七、相关功能

- **库存现有量**（仓库管理 → 库存现有量）：查看当前各位置的库存数量。
- **库存事务**（仓库管理 → 库存事务）：查看所有库存变动的流水台账。
- **仓库设置 / 库区定义 / 库位定义**（仓库管理 → 仓库设置 / 库区定义 / 库位定义）：维护仓库、库区、库位等基础资料，做调拨前请先把源和目标位置建好。
- [生产主流程](pro-workflow.md)：了解生产领料、生产入库等常规库存变动的完整流程。
- [库存盘点](wm-stock-taking.md)：盘点出盘盈盘亏后，回到本文的杂项入库 / 杂项出库调整账面库存。
