# 生产工单 / 排产任务 / 生产报工 / 流转卡操作手册

本文是生产四个核心页面的**按钮级操作手册**，面向计划员和班组长。从接单到发货的端到端流程故事见 [订单到交付主流程](pro-workflow.md)，异常的上报处理见 [生产异常：上报与处理](pro-exception.md)。

## 四个页面是什么关系

```
生产工单          排产任务            生产报工            流转卡
要做什么    →   哪道工序谁来做  →   实际做了多少    →   实物跟着走的卡
（产品/数量）   （机台/负责人/时间）  （数量/合格/参数）   （扫码报工、工序推进）
```

- **生产工单**：一张生产指令，写明做什么产品、做多少、什么时候要。
- **排产任务**：把工单的每道工序落到具体的机台（工作站）、负责人和时间。
- **生产报工**：工人做完一道工序后填报数量，班组长确认、审核后生效。
- **流转卡**：跟在实物（半成品/成品）上的身份卡，工人**扫卡上的二维码报工**，报工审核后卡自动推进到下一道工序。

## 一、生产工单

> 菜单路径：**MES 管理 → 生产管理 → 生产工单**

### 1. 建工单的两种方式

**方式 A：从销售订单转（有客户订单时）**

1. 打开 **MES 管理 → 销售管理 → 销售订单**，订单先「接单」进入已确认状态。
2. 在已确认的订单行上点「**生成工单**」，按向导选明细行、填数量并选工艺路线即可。
3. 生成的工单会带上**来源销售订单**号，方便反查；一张订单可以分多次、按部分数量转。

**方式 B：手工新增（备货、现货生产）**

1. 在生产工单列表点「**新增**」，进入两步向导。
2. **第一步「基本信息」**：工单编码可打开「自动生成」开关；填工单名称、工单类型（自制 / 外协）；点「选择」挑**产品物料**，再选该产品的**工艺路线**；填**计划数量**、**需求日期**；印刷、包装等要求按需填写。
3. **第二步「工序明细」**：系统按工艺路线自动带出各工序的 **BOM 物料清单**和**工序参数**；可按本单实际调整——增删物料行、改单位用量（自动显示预计总用量）、填参数调整值并注明调整原因；也可「添加工序」、上移 / 下移 / 移除工序。
4. 点「确定」提交。若改动的 BOM 或参数偏离了标准，系统会弹出「**检测到 BOM/参数偏离标准**」窗口，询问是否把这套定制规格**保存为新产品变体**——选"是"则下次返单可直接选用，无需重调；选"否"则仅本单微调。

> 工单建好后是「待生产」状态，**只有待生产的工单能修改和删除**。

### 2. 工单状态

| 状态 | 含义 | 怎么进入这个状态 |
|-----|------|----------------|
| **待生产** | 刚建好，还没开工 | 新增 / 转工单后默认 |
| **生产中** | 已开工 | 点「开工」并通过开工检查 |
| **已完成** | 全部做完 | 末工序报工审核、已生产数达到计划量后**自动完工** |
| **已取消** | 作废不再生产 | 待生产 / 生产中点「取消」，取消后不可恢复 |

> 筛选条件下拉里还有「已关闭」，用于归档展示，日常操作不会用到。

### 3. 列表里能看到什么

- **工序进度**：一排圆点代表各道工序，填满的百分比就是该工序已报工的比例，闪动的是当前进行中的工序，鼠标悬停可看明细。
- **当前工序**：显示「待开工·工序名 / 生产中·工序名 / 待完工 / 未排产」。
- **预计完工、剩余工时、按期**：系统按排产与报工实时测算，「将延期」会标红。
- **异常N**：红色角标表示该工单有 N 条未关闭的异常单，需先处理（见 [生产异常](pro-exception.md)）。

### 4. 行内按钮逐个说

| 按钮 | 出现条件 | 干什么 |
|------|---------|--------|
| **排产** | 待生产 / 生产中 | 跳到「甘特图排产」，给各工序指派机台和负责人 |
| **开工** | 待生产 | 执行四步开工检查（见下） |
| **齐套看板** | 总是 | 看每种物料的需求 / 可用库存 / 缺口 / 是否齐套，可一键生成领料单、采购单、入库单、退料单 |
| **修改 / 删除** | 仅待生产 | 调整工单内容或整张删除 |
| **取消** | 待生产 / 生产中 | 作废工单，不可恢复 |
| **进度** | 总是 | 全屏看板：工序进度、流转卡（子工单）、甘特图（实际叠加）三个页签 |
| **查看** | 总是 | 只读打开工单全貌；有未关闭异常时顶部出现红色警示区，可直接跳去处理 |

### 5. 开工检查（点「开工」后）

系统自动连走四步，每步通过打勾、不通过标红并给出原因：

1. **物料齐套检查**：逐种物料列出需求数量、可用库存和缺口。
2. **排产检查**：逐道工序检查执行方式（厂内机台 / 外协厂商 / 未排产）、机台和负责人是否落实。
3. **生成领料单**：自动按厂内 / 外协生成对应领料单。
4. **确认开工**：全部通过后工单变为「生产中」。

- 厂内工序**没派机台或没指定负责人**属于硬性拦截，弹窗底部会出现「**去甘特指派机台 / 负责人**」按钮，点它直接跳到甘特图排产处理。
- 完全没排产的急单，可走「**豁免开工**」：填写豁免理由后强制开工，理由会记入工单变更记录。

## 二、派产与排产任务

> 菜单路径：**MES 管理 → 生产管理 → 排产任务**；批量拖拽派产用 **MES 管理 → 生产管理 → 甘特图排产**

### 1. 排产任务怎么来

- **推荐**：在甘特图排产里把工单工序拖到机台时间线上，指派机台和负责人，任务自动生成。
- **手工**：在排产任务列表点「**新增**」——选生产工单后自动带出产品和工序列表，再选**工位**、填**排产数量**、**开始时间**和**总时长**（结束时间自动算出），还可给任务选个甘特图颜色。任务编码可打开「自动生成」。

### 2. 任务状态与行内按钮

| 状态 | 含义 |
|------|------|
| **待排产 / 正常** | 任务已建好，还没下达到工作站 |
| **生产中** | 已下发，工人可以开始干活报工 |
| **已完成** | 任务做完 |
| **取消** | 任务作废 |
| **不可开工**（红色标记） | 跟单质检不合格被锁定，需「质检放行」 |

| 按钮 | 出现条件 | 干什么 |
|------|---------|--------|
| **下发** | 待排产 / 正常 | 把任务下达到工作站，状态变为「生产中」。厂内任务必须**已派机台且已指定负责人**才能下发，否则报错提示去甘特指派 |
| **完成** | 生产中 | 标记任务做完。若完成的是**末工序**任务且工单产量已达标，工单会**自动完工** |
| **取消** | 未完成 / 未取消 | 作废任务 |
| **报异常** | 未完成 / 未取消 | 弹出异常上报窗口（质量数量 / 缺料 / 进度延迟 / 客户退货），提交后待主管处理 |
| **质检放行** | 显示「不可开工」时 | 打开跟单质检放行窗口，处理后解除锁定 |
| **修改 / 删除** | 总是 | 调整任务时间、数量等 |

> 工具栏还有「**导出**」，可把当前筛选的任务列表导出成 Excel。异常单生成的返工 / 补做任务也出现在本列表，带红色「异常」标记，「关联异常单」列可跳回异常详情。

### 3. 用户工作站绑定（配套功能）

> 菜单路径：**MES 管理 → 生产管理 → 用户工作站**

1. 点「**新增绑定**」，选择一批**人员**和一批**工位**，确定后批量建立绑定关系。
2. 列表里可用开关随时**停用 / 启用**某条绑定。
3. 用途：工人登记上下工时，系统优先列出他绑定的工位，**快捷选择不用翻全部工位**；绑定记录可在 **生产管理 → 上下工记录** 中查看。

## 三、生产报工

> 菜单路径：**MES 管理 → 生产管理 → 生产报工**

### 1. 报工的生命周期

```
工人填报 ──→ 待确认 ──(确认)──→ 已确认 ──(审核)──→ 已审核
```

- **确认**：班组长核对数量无误后点「确认」，确认后不可随意修改。
- **审核**：再点「审核」正式生效。**末工序的报工审核**会自动触发一串动作：累加工单已生产数量、**自动生成产品入库单和退料单**、把流转卡推进到「已完工」；工单产量达到计划量时工单**自动完工**。
- 工具栏提供「**批量确认**」「**批量审核**」，勾选多条一次处理；状态不符的会被跳过并逐条列出失败原因。
- 入库单无需手工建，在 **MES 管理 → 仓库管理 → 产品入库** 中查看；库存变化可在 **MES 管理 → 仓库管理 → 库存现有量** 核对。

### 2. 新增报工（PC 端）

1. 点「**新增报工**」，报工编码自动生成。
2. 点「生产任务」右侧放大镜**选任务**，工单、工序、工作站、产品全部自动带出。
3. **上机数量**由系统按工艺位置自动预填，人工改动的会留下修改痕迹。
4. 填**报工数量**、**合格数**、**不合格数**，按需填**工废**、**料废**、**待检测**、**生产批号**。
5. **流转卡**可不选——不选则自动挂到工单默认卡；需要分批追溯时选择对应卡。
6. 切到「**物料消耗**」页签：系统已按工单 BOM 自动带出消耗物料和数量，可增删行、改数量、填批次号。
7. 切到「**工序参数**」页签：按工序模板逐项填**实际值**，超出标准范围的自动标红「偏差」，提交前请核对。
8. 点「确定」保存，报工进入「待确认」。

> 报工类型区分三种：**自制报工**（本厂工序）、**外发代填**（本厂代外协厂商填）、**外发直填**（外协厂商自己填）。报工渠道支持 PC 端、Pad 端、扫码、微信。
> **串行工艺路线严格按顺序报工**：跳序、倒序提交会被系统拦下并提示。推荐产线用手机**扫流转卡二维码**报工，系统自动定位当前该报哪道工序，不会报错顺序（见 [二维码扫码作业指南](qr-code-scan.md)）。

### 3. 列表按钮与列

- **确认**（待确认时）、**审核**（已确认时）、**修改**、**删除**：单条流转操作。
- **痕迹**：打开「修改痕迹」抽屉，看这条报工的上机数量调整和编辑前后差异（时间、操作人、原值、新值、变更说明）。
- **检验状态**列：显示关联工序检的结果（检验合格 / 让步接收 / 待检验 / 检验不合格），点标签可直接跳到检验单查看。
- 工具栏「**导出**」可将报工列表导出 Excel。

## 四、流转卡

> 菜单路径：**MES 管理 → 生产管理 → 流转卡**

### 1. 卡从哪来

- **自动**：工单**开工时系统自动建一张默认流转卡**，数量等于工单计划量——不用手工建。
- **手工**：点「**新增**」，选生产工单（产品自动带出）、填**批次号**（可点「生成」自动编一个）、填**流转数量**；卡编码可打开「自动生成」。
- **拆卡**：一张卡数量太大想分两批走时，在「流转中」的卡上点「**拆卡**」，填拆出数量（必须小于原卡数量），原卡自动扣减、生成一张继承工单和产品信息的新卡。

### 2. 卡的状态与推进

| 状态 | 含义 |
|------|------|
| **流转中** | 正在厂内工序间流转 |
| **外协中** | 当前在外协厂商处加工 |
| **已完工** | 末工序报工审核通过，卡走完全程 |
| **已报废** | 卡片对应实物已报废 |

卡的推进**不用手工操作**：报工**审核**通过后，中间工序自动把卡的「当前工序」推进到下一道，末工序审核后卡变为「已完工」。点「查看」打开「**工序流转详情**」页签，可逐道工序看到状态（待加工 / 加工中 / 已完成 / 已跳过）、开始结束时间和合格 / 不合格数量。

### 3. 打印与扫码

1. 在列表行尾点「**二维码**」，弹窗显示该卡的二维码、卡编码和产品名。
2. 弹窗底部选择**标签纸规格**（默认 60×40mm，本机会记住选择），点「**打印**」。
3. 也可在列表勾选多张卡点工具栏「**批量打印**」，一次出多张标签。
4. 把标签贴在流转卡或实物上，工人**扫码即报工**。打印机配置和各端扫码方式见 [二维码扫码作业指南](qr-code-scan.md)。

## 五、工单变更

> 菜单路径：**MES 管理 → 生产管理 → 工单变更**

工单开工后不能再直接修改，重要调整走变更申请**留痕**：

1. 点「**新增**」，填**工单 ID**、**变更类型**（数量变更 / BOM 变更 / 日期变更 / 产品变更 / 工艺变更 / 其他）、**变更字段**、**原值**、**新值**、**变更原因**（必填）。
2. 变更单进入「**待审批**」，主管点行内「**审批**」后变为「已审批」，并记录审批人和审批时间。
3. 待审批的变更可「修改」「删除」；审批留痕后不可再动。

> 注意：变更单是**审批留痕**性质，审批本身不会自动改写工单数据——实际的物料、参数调整由授权人员在工单上操作（待生产工单可直接修改），变更单用来记录"谁申请、谁批准、为什么改"。开工时的「豁免开工」理由也会自动记入这里。

## 六、常见问题

**问：点「开工」被拦住了怎么办？**
答：看开工检查弹窗里哪一步标红——物料不齐去「齐套看板」生成采购单 / 领料单补料；提示未派机台或未指定负责人，点弹窗底部「去甘特指派」处理；完全没排产的急单可「豁免开工」并填理由。

**问：任务为什么没有「下发」按钮，或下发报错？**
答：只有「待排产 / 正常」状态能下发；厂内任务必须已在甘特图排产中指派了机台、并指定了负责人，缺一样都会被拦，按报错提示去甘特图补齐即可。

**问：报工提交后谁来审？审核后发生了什么？**
答：班组长在生产报工列表先「确认」再「审核」（也可批量）。审核后数量正式生效；末工序审核还会自动生成产品入库单、推进流转卡，产量够时工单自动完工。

**问：为什么提示我不能报这道工序？**
答：串行工艺路线要求严格按顺序报工，前一道没走完不能报后一道。拿不准当前该报哪道，直接扫流转卡二维码，系统会自动定位。

**问：工单数量或交期搞错了怎么改？**
答：工单还在「待生产」就直接「修改」；已开工的工单不能直接改，在「工单变更」里提交变更申请并审批留痕。

**问：工单为什么不能完工？**
答：两个常见原因：一是有未关闭的异常单（列表红色「异常N」角标），处理并关闭后才行；二是已生产数量还没达到计划数量，继续报工。

**问：一张流转卡的数量想分两批走怎么办？**
答：在流转卡列表对该卡点「拆卡」，填拆出数量，原卡自动扣减并生成一张新卡，两批各自流转、各自扫码报工。

**问：外协工序需要在本厂报工吗？**
答：外协工序的流转由外协收货驱动，卡会自动推进；需要代填产量时选报工类型「外发代填」，由厂商自己填的用「外发直填」。
