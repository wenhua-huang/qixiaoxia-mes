# 设备管理：设备类型与设备档案

设备管理用来维护全厂的**设备台账**：每台设备是什么型号、在哪个车间、现在是空闲还是在修。设备按"类型"分类管理，**先建好设备类型，再逐台登记设备档案**。排产派工时指派的是工作站（机台），设备档案通过"工作站关联设备"间接参与生产。

```
先建设备类型（分类树） ──→ 再建设备档案（逐台登记） ──→ 工作站里关联设备 ──→ 排产派到工作站
```

> 菜单路径：**MES 管理 → 设备管理 → 设备类型**、**MES 管理 → 设备管理 → 设备档案**。

---

## 一、设备类型：给设备分类

> 菜单路径：**MES 管理 → 设备管理 → 设备类型**

设备类型是一棵**分类树**，支持多级，例如"印刷设备 → 胶印机 / 数码机"。建议按车间习惯先规划好分类，再登记设备。

### 新增类型

1. 在类型列表中找到要挂的上级类型，点该行的「**新增**」（建顶级分类时直接点任意行的新增、上级留空即可）。
2. 填写**类型编码**（必填，保存后**不能改**）。
3. 填写**类型名称**（必填）。
4. 填**排序**（必填，数字，越小排越前）。
5. **启用状态**选"是"，点**确定**。

### 类型列表的常用操作

- 顶部可按**类型名称**、**是否启用**搜索；「**展开/折叠**」按钮一键收起或展开整棵树。
- 每行有「**修改**」和「**新增**」（在该类型下建子类型）。
- 列表里的"**启用**"开关可以直接停用某个类型（会弹确认框）。停用后该类型不再用于新建设备，已登记的设备不受影响。

> 设备类型**不提供删除**。不再使用的分类把"启用"关掉即可，历史数据完整保留。

---

## 二、设备档案：逐台登记设备

> 菜单路径：**MES 管理 → 设备管理 → 设备档案**

页面左侧是设备类型树，右侧是该类型下的设备列表。

### 新增设备

1. 点工具栏「**新增**」。
2. 填**设备编码**（必填，不超过 64 个字符，保存后**不能改**）。
3. 填**设备名称**（必填，不超过 255 个字符）。
4. 填**设备品牌**（选填）。
5. 选**设备类型**（必填，从分类树中选择）。
6. 选**所属车间**（必填，车间在"主数据管理"里维护）。
7. 选**设备状态**（新建设备默认"空闲"）。
8. 填**规格型号**、**备注**（均选填，支持多行），点**确定**。

### 各字段说明

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 设备编码 | 是 | 全厂唯一编号，**保存后不可修改** |
| 设备名称 | 是 | 设备的中文名称 |
| 设备品牌 | 否 | 生产厂家品牌 |
| 设备类型 | 是 | 从设备类型分类树中选择 |
| 所属车间 | 是 | 设备所在车间 |
| 设备状态 | — | 默认"空闲"，四种状态见下节 |
| 规格型号 | 否 | 设备的规格、型号参数 |
| 备注 | 否 | 其他补充信息 |

### 列表的常用操作

- 左侧点某个类型节点，右侧只显示该类型（含下级类型）的设备；类型树上方可按名称过滤节点。
- 顶部可按**设备编码**、**设备名称**搜索；「重置」会同时清除左侧类型树的选中。
- 列表里**点设备编码**可直接打开修改窗口。
- 工具栏支持**修改**（选中一条）、**删除**（可选多条，需二次确认）、**导出**（按当前搜索条件导出"设备台账数据.xlsx"）。

## 三、设备状态

| 状态 | 含义 |
|------|------|
| **空闲** | 设备可用，新建设备的默认状态 |
| **运行中** | 设备正在生产 |
| **保养中** | 设备停机保养 |
| **故障停机** | 设备故障，不能使用 |

> 设备状态**不会自动变化**，由设备管理员在设备档案里手动维护：设备开起来改"运行中"，送保养改"保养中"，坏了改"故障停机"，修好改回"空闲"。

---

## 四、设备与生产的关联

设备档案是**台账**，排产派工时不直接选设备档案里的设备，而是指派**工作站**（机台）。两者的桥梁在工作站页面：

1. 打开**MES 管理 → 主数据管理 → 工作站**。
2. 编辑一个工作站（如"1号印刷机"），在"**关联设备**"区域点「**添加设备**」。
3. 从设备档案中勾选对应设备保存。一个工作站可关联多台设备，也可不关联。

之后甘特图排产把工单工序拖到这台工作站上，就等于落到了对应的设备。设备状态（如"故障停机"）目前**只用于台账展示**，不会自动拦截派产——设备故障时请同时在排产上调整该工作站的任务安排。

## 五、常见问题

**问：设备编码填错了能改吗？**
答：不能，编码保存后即锁定。填错了请删除这台设备重新登记（名称、品牌等其他信息可以随时改）。

**问：设备类型能删除吗？**
答：类型页面不提供删除。分类不再使用时，把列表里该行的"启用"开关关掉即可，已登记的设备不受影响。

**问：设备状态会变成"运行中"是自动的吗？**
答：不是。四种状态全靠人工在设备档案里手动维护，系统不会根据报工自动切换。

**问：为什么在甘特图排产里看不到我刚加的设备？**
答：排产指派的对象是**工作站**（机台），不是设备档案。新设备需要先在"主数据管理 → 工作站"里建好对应工作站（或在现有工作站的"关联设备"里添加这台设备），才能在排产中使用。

**问：点左侧类型树的某个节点，右侧列表没变化？**
答：被停用的类型节点不参与过滤；另外如果之前输入过搜索条件，先点「重置」清掉再点节点试试。

**问：导出的表格包含哪些设备？**
答：按当前搜索条件导出（含左侧选中的类型和顶部编码 / 名称过滤），文件名是"设备台账数据.xlsx"。
