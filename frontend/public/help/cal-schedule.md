# 日历管理：班组、排班与节假日

日历管理回答一个问题：**某天、某个班次、是哪个班组在上班**。先把班组建起来，再编一份排班计划，系统就会按天把班组排到每个班次上；排班结果不仅在排班日历里可查，还会直接影响甘特图自动排产——节假日和周末不会被排进生产任务。

```
节假日设置（哪天休/哪天调休上班）
        │
班组设置（谁、属于哪个班组）──→ 排班计划（哪段时间、几个班次、哪些班组轮）
                                        │ 点「完成」
                                        ▼
                              按天生成排班明细 ──→ 排班日历查看
                                        │
                                        ▼
                          甘特图自动排产跳过休息日、按班次时间推算完工
```

> 菜单路径：**MES 管理 → 日历管理** 下的四个页面：**节假日设置**、**班组设置**、**排班计划**、**排班日历**。

---

## 一、建议的配置顺序

1. **节假日设置**：先把法定节假日、调休上班日标出来（只做一次，后续按需补）。
2. **班组设置**：建好班组并维护班组成员。
3. **排班计划**：新建计划 → 保存 → 重新打开配班次、配班组 → 点「完成」生成整段排班。
4. **排班日历**：分类 / 班组 / 个人三个视角核对排班结果。

> 前三步缺任何一步，排班日历里都是空的；排班日历本身只读，不能在上面改排班。

---

## 二、节假日设置

> 菜单路径：**MES 管理 → 日历管理 → 节假日设置**

页面是一张月历，每一天默认显示深色「**班**」标签（默认周一到周五上班、周六日休息的判定见"常见问题"）。

设置某一天为休息或调休上班：

1. 在月历上**右键点击**目标日期。
2. 在弹出的对话框中选择类型：**假**（休息）或**班**（调休上班）。
3. 点**确定**。设为"假"的日期显示绿色「**休**」标签；同一天重复设置会覆盖原记录。

- 法定节假日、公司放假：设为**假**。
- 周末调休要上班的日子：设为**班**（这一天会被当作工作日，排产不跳过）。
- 同一天既设过"假"又设过"班"时，**以"班"为准**。

---

## 三、班组设置

> 菜单路径：**MES 管理 → 日历管理 → 班组设置**

### 新建班组

1. 点**新增**。
2. 填**班组编号**（也可打开"自动生成"开关由系统编号）、**班组名称**、**班组类型**（白班 / 夜班 / 中班 / 轮班）。
3. 备注选填，点**确定**保存。

### 维护班组成员

班组必须先保存，再加成员：

1. 在列表中点该班组的**修改**（或点班组编号查看）。
2. 对话框下方出现成员区，点**新增**，在弹出的系统用户列表中**勾选一个或多个人**，确认后即加入班组。
3. 选中成员点**删除**可移出班组。

> 成员就是系统登录用户。报工、上下工打卡时，系统会按操作人自动记下他所属的班组（一个人属于多个班组时，取最早加入的那个），所以人一定要先进班组，报表里才有班组口径的数据。

---

## 四、排班计划

> 菜单路径：**MES 管理 → 日历管理 → 排班计划**

排班计划 = 一段时间 + 几个班次 + 几个班组，点「完成」后系统按天生成"哪天哪班谁上"的明细。

### 第 1 步：新建计划

1. 点**新增**。
2. 填**计划编号**（可用"自动生成"）、**计划名称**、**开始日期**、**结束日期**、**班组类型**。
3. 选择**轮班方式**：单白班 / 两班倒 / 三班倒。
4. 非单白班时再选**倒班方式**（按月 / 按天），选"按天"时填倒班间隔天数。
5. 点**确定**保存。此时计划是"编制中"状态。

### 第 2 步：配班次

1. 回到列表，点该计划的**修改**，对话框下方出现「班次」「班组」两个页签。
2. 在**班次**页签点**新增**：填**序号**（第几班）、**班次名称**（如早班 / 晚班）、**开始时间**、**结束时间**。
3. 两班倒配 2 个班次、三班倒配 3 个班次，按序号对应早 / 中 / 晚。

### 第 3 步：配班组

1. 切到**班组**页签，点**添加**，从已有班组中勾选一个或多个。
2. 数量必须匹配轮班方式：**两班倒必须恰好 2 个班组，三班倒必须恰好 3 个班组**，否则点完成时会被拦下提示。
3. 点左侧班组列表的某一行，右侧可以查看该班组的成员，确认人没配错。

### 第 4 步：完成编制

1. 点对话框底部的**完成**，确认提示"完成后将不能更改"。
2. 系统按计划起止日期**逐天生成排班明细**：每天各班次安排一个班组，班组按天依次轮换（两班倒时两个班组每天白班 / 夜班互换）。
3. 计划状态变为"**已确认**"。已确认的计划不能修改、不能删除；排错了只能到排班日历里核对后，重新建一份正确的计划。

---

## 五、排班日历

> 菜单路径：**MES 管理 → 日历管理 → 排班日历**

只读查看，三个页签三种视角：

| 页签 | 看什么 | 怎么用 |
|------|--------|--------|
| **分类** | 某类班组（白班 / 夜班 / 中班 / 轮班）每天各班次轮到谁 | 左侧选班组类型，上方可切换月份 |
| **班组** | 指定班组整月的上班安排 | 左侧选班组 |
| **个人** | 指定员工整月的上班安排 | 上方选人员（点放大镜从用户列表选） |

日历格子里的颜色含义：

- 绿色（太阳升起图标）：当天第 1 班（早班）。
- 橙色（太阳图标）：三班倒时的第 2 班（中班）。
- 深色（月亮图标）：夜班（两班倒的第 2 班、三班倒的第 3 班）。
- 绿色「**休**」标签：节假日，当天不排班。

---

## 六、排班对生产的影响

- **甘特图自动排产**：排产时系统自动从最近的工作日开工，**跳过节假日、调休之外的周末和未排班的日子**，并按班次的起止时间推算每道工序的完工时间。甘特图上非工作日会以底色区分，一眼能看出任务为什么跨了周末。
- **报工 / 上下工**：报工单和上工打卡会**自动记录操作人当时所属的班组**（快照，之后改班组不影响历史记录）。没有班组的员工也能正常报工，不会被拦——只是该记录没有班组信息。
- **不校验班次**：系统不会拦"非本班次时间报工"，班次目前用于排产推算和台账查看，不做打卡考勤。

> 判断某天是否工作日的优先级：**节假日设置 > 当天有排班明细 > 默认周一至周五上班**。

## 七、常见问题

**问：排班日历里为什么是空的？**
答：三个常见原因——排班计划还停留在"编制中"没点「完成」；计划里没配班组或班次；查看的月份不在计划起止日期内。按"配置顺序"一节逐项核对。

**问：点「完成」时提示"两班倒需要配置两个班组"怎么办？**
答：回到计划的「班组」页签，把班组数量调到和轮班方式一致（两班倒 2 个、三班倒 3 个），再点完成。

**问：计划点完成前忘了配班次，日历里没东西，怎么办？**
答：没配班次的计划点完成后不会生成任何排班明细。已确认的计划不能再改，请删除不可行时新建一份计划：配好班次和班组后再点完成，然后到排班日历核对。

**问：排班计划确认后发现排错了，能改吗？**
答：不能。"已确认"的计划在页面上没有修改和删除入口。正确做法是新建一份覆盖后续日期的正确计划并确认；历史排班明细保留备查。

**问：周六显示"班"但我们不上班，需要处理吗？**
答：需要。默认规则是周一到周五算工作日、周六日算休息；如果公司周六也休息，不用设；如果某个周六要上班（调休），在节假日设置里把那天设为"班"，排产才会把任务排进去。

**问：员工调班组了，之前的报工记录算哪个班组？**
答：报工和打卡保存时就固化了当时的班组快照，调班组只影响之后的新记录，历史数据不回溯。

**问：删除班组会影响已经生成的排班吗？**
答：班组的删除只是删掉班组本身，已生成的排班明细和日历记录仍保留当时的信息。但排班日历"班组"页签里就再也选不到这个班组了，删除前请确认。
